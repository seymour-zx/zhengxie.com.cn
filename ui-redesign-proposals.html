全站 UI 重设计 · 四套方案（含亮/暗双模）

以第 1 轮圆桌共识为地基：红金白"奢华尊贵"是第一眼差异化资产、需继承；"可信政务垂类"为北极星；动效克制（减法优先）。下列方案均为全量 token 重设计，亮暗同步。

圆桌已吸收的硬约束：① 亮色焦点环换深金 #9E7E36（WCAG 2.4.7，原亮金仅 ~1.9:1 不达标）；② 广告区用金 30% 分隔线 + "广告"徽章明确区隔（防误认=护"可信"资产）；③ 暗色描边柔和化；④ `.card__link` 直角统一为圆角（消除风格不一致）；⑤ 去"土味"——金作点缀级、描边柔和。交互哲学（hover/阴影/闪动）由我定：悬停=抬升+描边提亮+柔影；入场=淡入上浮(尊重 reduced-motion)；无闪动/无金光扫（闪动伤信任且不符 a11y）。

1

朱玺政务 ★★★ 最推荐

亮：暖白 #FCFAF7 / 朱红 #C0392B / 暖金 #C2A35A ｜ 暗：暖炭 #1E1B1F / 朱砂 #E2604E

定位：当前红金白的精修版。红由深酒红(易显土/血感)→干净朱红；金描边柔和、焦点环达 WCAG；暗色提亮去阴森。完整吸收圆桌 #5 七项修复。

理由：零品牌损耗、风险最低、立即可上线；第一眼"正式体面"资产保留，同时解决年轻用户"偏土"与 a11y 硬伤。是"继承共识 + 修缺陷"的最优解。

侧重点：继承品牌 · 修 a11y · 最低风险 · 立即可上 交互：圆角 10px、抬升 6px、柔红影；衬线标题；动效 .18s 轻快。无闪动。
2

翰墨丹青 ★★☆ 文化向推荐

亮：宣纸 #FBF9F4 / 朱砂 #C8442E / 黛青交互 #3E7C6E ｜ 暗：墨蓝绿 #16222A / 青瓷 #5FB3A1

定位：把"正式官气"转译为"书卷文人气"。基底转宣纸/墨青，朱砂仅作主色点缀，青瓷绿作交互强调（链接/hover/focus），金退为弱描边。

理由：最优雅地回应圆桌"正式但不土"——用文化厚度替代官样；护眼、权威、长读舒适。代价：偏离红金识别，需评估品牌记忆度。

侧重点：文化厚度 · 书卷气 · 护眼长读 · 拉近代际 交互：圆角 6px(更挺括)、抬升仅 3px(近乎平贴)、墨晕式淡影；衬线标题；动效 .22s 舒缓、克制。
3

鎏金现代 ★★☆ 年轻向推荐

亮：纯白 #FFFFFF / 鲜红 #E23B2E / 香槟金点缀 ｜ 暗：石墨 #191C22 / 鲜红 #EC5A4C / 金转中性灰

定位：红金白的"现代 SaaS"表达。纯白大留白、标题改无衬线、圆角 14px、金仅作发丝线/火花点缀，红更鲜亮可控。

理由：直接化解 24 岁用户"不是给我用的"痛点——通透、轻盈、年轻；仍保留红作品牌锚点。代价：弱化"官气/可信政务"信号，对核心政务人群识别度略降。

侧重点：现代通透 · 大留白 · 拉近年轻 · 弱化官气 交互：圆角 14px、抬升 8px、双层柔影；无衬线标题；动效 .2s 顺滑、按钮按压微缩。
4

赤金典藏 ★☆☆ 极致奢华·备选

亮：奶咖 #F7F1E6 / 深酒红 #8E1B1F / 富金 #B8902F ｜ 暗：深咖 #1A1410 / 亮金 #D4AF37

定位：把"尊贵"推向极致——奶咖底、深酒红、富金描边、衬线通体、深影浮雕感。比现版更"重"更"藏"。

理由：品牌表达最强烈、收藏质感最强。但圆桌明确警示"红金易俗/土"且年轻用户最劝退——风险最高，仅当你要加倍强化高端政务人设时选。

侧重点：极致尊贵 · 收藏感 · 品牌最强 · 土味风险最高 交互：圆角 8px、抬升 5px、深影+金描边发光；衬线标题；动效 .28s 慢雅。

本页为设计预览稿（非站点文件）。选定方案后，我将把对应亮/暗 token 集写入 style.css 的 :root 与 [data-theme="dark"]，并同步 index.html 的 theme-color 与焦点环。改文件前需你确认。
