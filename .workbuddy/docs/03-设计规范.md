> 定位：本文档是 CONVENTIONS 圆桌 E4「设计 token 文档」的落地，把散在 CSS 与 README 里的视觉约束收成单一权威表。

---

## 1. 设计语言总纲（三条不可协商）

1. **正红为主，大面积留白打底，金色只做点缀** —— 金色是描边/高亮，不是第二主色。
2. **清爽克制，不堆砌** —— 加元素前先问"能不能删"；装饰性元素零容忍。
3. **任何 UI 都服从这套语言** —— 不得擅自引入新主色、新视觉调性。

**暗色禁止**：偏蓝、偏紫、科技冷淡、廉价渐变。暗色是"朱玺政务"调（暖炭底 + 朱砂 + 香槟金），护眼且不失庄重。

## 3. 字体规范

| 项 | 值 | 说明 |
|---|---|---|
| 基准字号 | `html { font-size: 16px }` | **不得删除** |
| 文本自适应 | `-webkit-text-size-adjust: 100%` + `text-size-adjust: 100%` | **不得删除**（禁移动端自动膨胀） |
| 表单继承 | `input, textarea, select, button { font-family: inherit }` | **不得删除** |
| 无衬线栈 | `--sans: "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` | 正文/UI |
| 衬线栈 | `--serif: "Noto Serif SC", "Songti SC", "SimSun", serif` | 标题/庄重场合 |
| 行高 | `line-height: 1.5` | body 基准 |
| 链接色 | `a { color: var(--red) }` | 全站统一 |

> 三者（16px / text-size-adjust / font-family:inherit）是**跨浏览器一致性基准**，删除会导致字体在部分浏览器异常放大。

## 4. 间距与布局

| 项 | 值 |
|---|---|
| 容器最大宽度 | `1200px` 居中，桌面不铺满 |
| 视口高度 | 用 `100dvh`（适配移动端地址栏） |
| 响应式 Grid | 手机 2 列 / 平板 3 列 / 桌面 4 列（`repeat(2/3/4, 1fr)`） |
| 卡片 Grid 防溢 | `min-width: 0` |
| 卡片圆角 | `--radius: 8px` |
| 阴影（静/悬停） | `--shadow` / `--shadow-hover` |
| 广告容器 | 左右零 margin/padding、无包裹样式，只留上下间距 + 右上「广告」小字标签 |

## 5. 无障碍标准（WCAG 2.1 AA）

| 要求 | 标准 | 现状 |
|---|---|---|
| 正文对比度 | ≥ 4.5:1 | `--text`/`--bg` 亮色 ≈ 15.9:1 ✅；暗色 ≈ 11.5:1 ✅ |
| 次要文字对比度 | ≥ 4.5:1 | `--text-sub`/`--bg` 亮色 ≈ 7.4:1 ✅；暗色 ≈ 6.1:1 ✅ |
| 大字号/图标对比度 | ≥ 3:1 | `--focus-ring` 亮色 ≈ 4.6:1 ✅ |
| 焦点可见 | `:focus-visible { outline: 2px solid var(--focus-ring); outline-offset: 2px }` | ✅ 已实现 |
| 图标语义 | 纯图标按钮必带 `aria-label` | 需逐页核验（见 09-用例模板 UC-A11Y） |
| 图片替代文本 | 所有 `<img>` 必带 `alt` | ✅ 实测 9/9 有 alt |
| 表单标签 | 每个 input/textarea/select 必有关联 label | submit 页需核验 |
| 动效 | 尊重 `prefers-reduced-motion` | ⬜ 待补 |

## 6. 暗色模式的三条硬规则

1. **仅跟随用户手动切换**，不跟随系统偏好（`prefers-color-scheme`）。
2. **状态存 `localStorage('zx_theme')`**，加载前内联脚本读取并设 `data-theme`，防 FOUC（闪烁）。
3. **切换按钮固定在页脚工具簇**，不得占用置顶吸顶区。

## 7. 已确立的视觉细节（踩过坑，勿重犯）

| 项 | 规则 | 原因 |
|---|---|---|
| 分类按钮 | **不放数量/计数徽章** | 与结果计数行重复 |
| 暗色切换按钮 | **不占置顶吸顶区**，固定页脚工具簇 | 吸顶区位置紧张 |
| 卡片文本 | **允许框选/复制**（已移除 `user-select:none`） | 链接点击与文本选择互不冲突 |
| 空结果状态 | **不做"清除所有筛选"按钮**，只显示提示文案 | 与筛选行的"清除筛选"重复 |
| Logo 按钮 | 同时带 `category-nav__logo` 与 `category-btn` 两个类，且 **logo 样式块必须放在 `.category-btn` 系列之后** | 否则被覆盖成圆形白底 |
| 卡片图片 | 统一 WebP 且保留透明通道（RGBA） | 否则透明 logo 被填黑 |

---

## 8. 禁止清单（设计层红线）

- ❌ 引入新主色或第二主色（金只能点缀）。
- ❌ 暗色使用偏蓝/偏紫/科技冷淡/廉价渐变。
- ❌ 删除 `html` 16px / `text-size-adjust:100%` / 表单 `font-family:inherit` 任一项。
- ❌ 在分类按钮加计数徽章、在空状态加"清除所有筛选"按钮。
- ❌ 把暗色切换放进吸顶区。
- ❌ 卡片内容设 `user-select:none`。
