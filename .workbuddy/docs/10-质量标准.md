## 1. 严重度分级

| 级别 | 定义 | 处置 |
|---|---|---|
| 🔴 **红线 P0** | 阻断使用、安全/合规风险、SEO 生命线受损 | **任一不过 = 禁止上线**，必须修复后重测 |
| 🟠 **严重 P1** | 明显缺陷，影响体验或收录，但不阻断主路径 | 限期修复（≤ 7 天），可记录后上线 |
| 🟡 **一般 P2** | 体验瑕疵、优化项 | 进整改清单，按排期修 |
| ⚪ **提示 P3** | 观察项/建议 | 记录，不强制 |

## 3. 发布闸门判定规则

```
IF 任一 🔴 红线项 = 未通过
    → 禁止上线，修复后重测
ELIF 🟠 严重项 > 0
    → 可上线，但须：①记录每条未通过项 ②指定修复期限（≤7天）③进整改清单
ELIF 🟡 一般项 > 0
    → 正常上线，进整改清单按排期修
ELSE
    → 全绿上线
```

**豁免规则**：任何红线项豁免必须**用户显式同意**，并在迭代卡记录豁免理由与风险；豁免不消除债务，下次部署重新判定。

## 4. 度量方法（保证数字可复现）

| 类别 | 方法 | 命令/工具 |
|---|---|---|
| 体积 | 文件系统字节数 | `ls -l` / `find -exec ls -l` |
| 覆盖率 | 正则统计 HTML | Python 扫描脚本（08 §3） |
| 断链 | 文件存在性 + HTTP 探测 | 扫描脚本 + `check_links.py` |
| 对比度 | 色值计算 | 用 03-设计规范 §2 token 值算 |
| LCP/CLS | 浏览器性能面板 | Lighthouse / Web Vitals |
| 第三方请求 | Network 面板 | 浏览器 DevTools |

> **纪律**：所有质量数字必须来自可复现的度量方法，禁止凭印象填报。基线数字变化时同步更新 [00-索引](./00-索引.md) §5 快照。
