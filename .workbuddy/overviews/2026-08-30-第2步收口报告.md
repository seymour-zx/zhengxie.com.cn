## 一、产品本质（一句话，不可偏离）

> **主题卡片陈列馆 / 百科索引**：每张卡片是一个词条（机构/人/书/电影/学校……无限制），像陈列馆一样陈列"世界上存在过/存在着的事物"，并给出相关链接（若有）。形式借鉴传统导航外观，但绝非导航网站。

**旧世界被弃根因**：agent 全程用「传统导航网站」定义本项目 → 一切方案违背造物主本意（如反复要求"删无链接卡片"）。

## 二、核心决策（D/N 全表 + 原因）

| # | 决策 | 原因（摘要） |
|---|---|---|
| D-01 | 综合全品类导航；政协+民主党派=首页频道专题 | zhengxie.com.cn 吃政协自然流量；纯垂直违背本意 |
| D-02 | 党派归并政协专题；gov 含人大；搜索框=自用放搜索专题页；命名标准=准确无歧义 | 党派体量小；人大初期并入；首页搜索框泛滥对导航体验负影响；差异化思路违背准确性 |
| D-03 | 首页只放政协+民主党派（数千卡）；其他专题全部子频道 | 首页数千卡已占满；首页只有一个位置 |
| D-04 | 卡片必须有，无链接也保留（"无网址/未找到"展示） | 陈列馆本质；"存在但无网址"也是信息；网站被淘汰是网络必然 |
| D-05 | 链接行不限制数量（官网/微博/公众号/百科页…）；xlsx 10 位=预留 | 卡片相关一切可挂；10 位为人工维护方便 |
| D-06 | enabled 保留（true=展示，空=暂不展示）；字段名正确 | 维护暂停机制；业界布尔惯例无歧义 |
| D-07 | 14 页结构保持+更名；必落地拼装化+随机漫步改造 | 结构成熟；改造是页面实现必做项 |
| D-08 | 百科索引形态（词条可泛化，挂外部百科页） | 卡片泛化；只做索引不做内容 |
| D-09 | 构建：继承 build/build_homeplus（含片段化改造）+check_links（后按需改）；砍 collect_meta/sync_star_sprite | build 管线成熟；check_links 死链检测有用；后两者已失效/被覆盖 |
| D-10 | verify_site 八项校验 → 输出 **xlsx 报告 + 造物主拍板**（人治闸门） | 机器发现问题、造物主决定上线；工具提供事实、人拍板 |
| D-13 | 卡片三类型全保留（type1 主/type2 横版含广告/type3 竖版封面人物） | 基础形态；未来广告/书/电影/人物专题用 |
| D-15 | 广告=配置化控制（政务零广告字段留空；非政务可有） | 广告放否由 xlsx 控制；改配置不改代码 |
| D-16 | 统计/广告/搜索框/导语=片段化拼装引擎（xlsx 字段控制） | 当前境外保留三件套；迁移境内时 xlsx 关闭 GA4/AdSense |
| D-17 | 旧世界=边吸边删（分类提取→提纯→决策→吸收→删除）；剩壳删壳 | 旧世界正常运行中切断联系，仅资料库；逐步消耗 |

**命名（N-01~07）**：搜索工具/search、政务导航/gov、专题导航/topics、人大/renda｜**政务类专题名必带第三方属性词**（DEC-008）
**名称/slogan 永不改**：正协导航 +「让每一次寻找，都不止于找到」

## 三、边界（做/不做，全部拍板）

**做**：卡片陈列（无链接标注"无网址"）、链接行多链接、综合全品类+政协流量、整站级可信信号（细粒度缓做）、站内搜索/收藏/暗色/**随机漫步（新玩法：随机展示不跳转+分类容器 sticky 切换+广告双策略）**、反馈=邮件/收集表
**不做**：灰色服务网站收录（按网站性质非按词）、冒充官方（切割第一优先）、站内生成政务民生资讯（只聚合挂外链）、逐卡徽章、假提交页面（收录/反馈=在线收集表，多平台并列，填写人仅见自己内容）、百科内内容
