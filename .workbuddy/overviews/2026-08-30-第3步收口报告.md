## 一、卡片字段字典（cards.unified.xlsx，33 列）

**32 列继承**（row_seq / dir_path / cat_id / cat_name / card_layout / card_title / card_desc / card_media / card_tags / card_id / card_order / link_1~10_name+url / enabled）
**+ 1 列新增 `is_ad`**：True = 广告卡（随机漫步注入 + "广告"标识）；其他不是；独立于 card_layout（type1/2/3 均可标记）

- 无链接卡：**空行占位**（与旧世界一致，不新增字段）
- `card_order`：字段保留但**不参与渲染**（预留，与旧世界一致）

## 二、页面字段字典（pages.unified.xlsx，11 列）

**6 列继承**（dir_path / title / description / keywords / channel_intro / enabled）
**+ 5 列拼装引擎**：
| 列 | 规则 |
|---|---|
| channel_intro_enabled | True 且有内容才显示导语（AND） |
| ad_slots | `1,3` 式；空 = 零广告代码（meta 零 AdSense） |
| stat_ga4 | True/空 |
| stat_baidu | True/空 |
| search_box | True/空 |

**拼装原则**：页面模块全部由 xlsx 决定，**py 无页面特判**（首页/搜索专题页无硬编码）。

## 三、排序规则（与旧世界一致）

1. 分类按钮 = xlsx 分类名**首次出现顺序**（手工排分类行）
2. 卡片 = 先按 card_layout（type 1→2→3 分行），组内按 **row_seq** 从小到大
3. **py 不重排、不自动编号**；造物主手工维护 row_seq + 分类行位置

## 四、xlsx 读取健壮性（build 规格）

读第一个 tab / 自动识别表头行 / 列乱序不影响 / 额外列安全（造物主自加备注列不崩）

## 五、分类体系（定案）

**首页（/）**（约 15 按钮）：全国政协 / 省级政协(31) / 副省级城市政协(15，单列) / 地级政协 / 县级政协 + 民革/民盟/民建/民进/农工党/致公党/九三学社/台盟 + 工商联 + 相关机构（组织内 row_seq 排序：中央→省→市）
**政务导航（topics/gov）**：全国/直辖市/省/自治区/国务院/国家平台/组成部门 + **人大（单设类）**
**搜索工具（topics/search）**：综合搜索/购物/社区知识/视频/开发/工具/数据库/素材/学术搜索/AI对话

## 六、收集表字段（定案）

**收录表**：词条名 / 分类建议 / **希望收录在哪个页面**（dir_path）/ 网址 / 链接名称 / 描述 / 标签 / 收录理由 / 联系方式
**反馈表**：反馈类型 / **指向哪个页面**（反馈针对的页面）/ 反馈内容 / 联系方式（可选）
权限：收集表模式（填写人仅见自己内容）；平台 = 多家主流并列。
