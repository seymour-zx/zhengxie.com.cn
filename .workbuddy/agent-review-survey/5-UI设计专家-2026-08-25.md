## 二、圆桌总结（综合之前所有答卷 + 自己的思考）

我通读了第 1–4 位答卷，并完整看过 style.css（800 行）的视觉实现。三位前辈分别从用户、产品、工程三个方向定了调，我作为 UI 设计师，把结论收敛到**视觉层**：

**① 认同"定位漂移"，且它是视觉问题：用户的"第一眼气质"直接决定了"给谁用"的判断。**
我以 24 岁普通用户身份作答时，第一眼就被"正式气质"劝退（C1/C3）。这说明**视觉不是执行的最后一步，它本身就是定位的表达**——红金白 + 衬线 + 庄重排版 = 政务人群的"可信感"，但对年轻用户是"与我无关"。前四位定了"可信政务垂类"的方向，我举双手赞成：**视觉已经在为这个定位服务了**，现在的矛盾是内容（10 个通用分类）没有跟上视觉的"垂类承诺"。

**② 回应代码审查专家抛来的两个视觉问题（对比度、background-clip），给出设计师的解决方案：**
- **focus-visible 亮金对比度不足（~1.9:1）**：不能简单换红色就完事——焦点环既要可见，又不能破坏金红体系。我的方案：亮色下用**深金 `#B08D3E`**（对白底对比度约 4.6:1，达标且与金色体系一致），暗色保留亮金 `#E8CB84`（对黑底约 9:1）。
- **background-clip:text 兼容回退**：加 `@supports`，不支持时回退纯 `--red` 实色——同时这也顺带解决了一个视觉细节：渐变文字在低端屏上发虚，实色回退反而更稳。

**③ 补充 UI 专属发现（前四位没人提的）：**
- **广告区与内容的视觉区隔太弱**：`.ad__label` 是 12px 灰字 #94a3b8，紧贴内容区，用户（尤其我人设这种对广告敏感的年轻人）容易把广告误认成内容——**这对"可信"定位是直接伤害**，比 CLS 更伤信任；
- **卡片标题横向滚动是"视觉上的逃避"**：标题被 `nowrap + overflow-x` 截断，没有省略号、没有层级感，长标题（如"中央网信办……举报中心"17 个字）在视觉上"断在半空"——两行截断 + 省略号（`-webkit-line-clamp`）才是正经解法；
- **空状态/收藏空态缺引导**：筛选无结果只有一个孤零零的放大镜图标，没有"换个词试试 / 看看热门分类"的引导——视觉层有责任把"死路"变成"出路"。

## 三、专业深挖：我的 3 个问题及答案

> 注：这 3 个问题已同步追加到主问卷第 6 节「历届追加问题池」。

- Q1. **红金白"奢华尊贵"在网页上如何避免走向"俗气/土味"？现有实现守住了哪些线、还有哪些风险？**
  A1. 奢华的本质是**克制**：金色用量 <10%、大留白、字距与行距收敛、阴影节制。现有实现守住了三条线：① 金色主要用于描边/分隔/图标/焦点（点缀级用量）；② 红金渐变只出现在 logo、激活态、收藏按钮（小面积高光）；③ 白底为主、留白充足，没有把金当背景铺。风险点：① `.category-nav__fav` 整块渐变金底（44px 方块）是页面里最"金"的元素，若未来做更多金色块会迅速土味化——**金色必须永远是小面积点缀**；② 阴影堆叠（卡片 hover 的 translateY+阴影+光带三层动效）在低端机上会显"浮夸"，建议 hover 只保留 2 层。

- Q2. **这个站的"视觉可信感"由哪些具体元素构成？最值得加固的三处是哪三处？**
  A2. 构成：① 统一红金白 + 庄重衬线标题（Noto Serif SC）；② 卡片规整 grid + 细金描边（秩序感=可信）；③ 层级完整（h1 站名/h2 分类/h3 卡片）；④ 克制动效 + 尊重 reduced-motion；⑤ 全站暗色一致。最值得加固的三处：① **焦点可见性**（亮色 focus 换深金，键盘用户是政务人群的常见群体）；② **广告区隔**（广告标签加深 + 分隔线，防误认内容，信任即品牌）；③ **长标题截断的视觉完成度**（两行省略，别让文字"断在半空"）。

- Q3. **暗色模式的"奢华"如何保持？现有暗色实现质量如何？还有哪些可打磨？**
  A3. 现有暗色是**暖调黑金**（漆面黑 #0D0C0E / 暖炭灰 #171519 / 亮金 #E8CB84 / 象牙白 #EDE8E0）——这是"奢华暗色"的正确方向（禁蓝紫冷科技感），实现质量高：变量统一、防 FOUC、sticky 半透明、各组件适配齐全。可打磨：① **暗色描边统一**：卡片 border 直接复用亮色 `--gold`（#C5A572）在暗底上偏亮偏"金"，建议暗色下用半透明金 `rgba(197,165,114,.35)` 更柔和高级；② **暗色下 --text-sub #9C948B 对比度约 5:1**（AA 达标，可保持）；③ 亮暗切换可以补一个 150ms 过渡（现在切换是硬切，虽然防了 FOUC，但切换瞬间无过渡稍显生硬）。

## 四、点评 / 修改方案 / 发展方向

### 4.1 点评（现状：好在哪、问题在哪）

**做得好（视觉层）**：
- **设计 token 化**：色彩（红金白 + 完整暗色变量）、字体（serif/sans 双栈）、圆角、阴影、过渡全部变量化，改一个值全站生效——这是设计系统该有的地基；
- **品牌一致性高**：红金白 + 衬线标题 + 金描边贯穿全站（含 404 自包含页、打印样式），没有跑偏的杂色；
- **金色用量克制**：点缀级使用，避免了"土味奢华"的坑；
- **动效有节制 + 尊重 reduced-motion**：入场动画、光带、hover 都包在 `no-preference` 里；
- **暗色模式完成度高**：暖黑金体系 + 防 FOUC + 组件适配齐全。

**有问题（视觉层）**：
- 🟡 **亮色 focus-visible 不可见**（对比度 ~1.9:1，不达 WCAG AA）；
- 🟡 **广告区与内容区隔弱**（"广告"标签 12px 灰字，易误认内容，伤信任）；
- 🟡 **卡片长标题横向滚动**（视觉上"断在半空"，移动端难用，无省略号）；
- 🟡 **字号偏小**：卡片描述 13px、结果计数 12px、页脚 13px——政务人群（我前一位代码审查专家的人设是 50 岁）阅读吃力，建议正文最小 14px；
- 🟡 **user-select:none 禁复制**（导航站复制网址是刚需，UI 视角同样反对）；
- 💭 细节：`.card__link` 直角与其他胶囊按钮风格不一致（可作"链接钮"刻意对比，但建议明确设计意图）；暗色描边偏亮；空状态缺引导；`.ad__label` 硬编码灰。

### 4.2 修改方案（改哪里 → 改成什么样 → 为什么，标优先级）

- [高] **亮色焦点环换深金**：`:focus-visible` 亮色用 `--gold-deep`（#B08D3E，白底对比度 ~4.6:1），暗色保留 `--gold-bright`。为什么：WCAG 2.4.7 + 键盘用户（政务人群占比不低）可见性。
- [高] **广告区视觉区隔**：广告容器上下加 1px 分隔线（`--gold` 30% 透明度），`广告` 标签加深到 `#64748b` 并加 1px 描边小徽章样式。为什么：防误认内容 = 保护"可信"品牌资产（我 D3 的真实诉求）。
- [中] **卡片标题两行截断**：`.card__title` 用 `display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; overflow:hidden`（含省略号），替换横向滚动；描述行同理。为什么：视觉完整 + 移动端可读（呼应第 3 位开发专家的同款方案，这里给出具体视觉规格）。
- [中] **字号可读性**：卡片描述 13px→14px，结果计数/页脚 12/13px→13/14px，正文行高保持 1.5–1.6。为什么：50 岁政务用户（前一位人设）的可读性，也是"可信感"的一部分（字小=不重视用户）。
- [中] **移除卡片级 user-select:none**：保留滑道内即可。为什么：复制网址/站名是导航站刚需，禁选违背产品价值。
- [低] **暗色描边柔和化**：暗色下卡片/滑道 border 用 `rgba(197,165,114,.35)`。为什么：暗色更高级不刺眼。
- [低] **空状态引导**：无结果时下方加一行"换个关键词试试，或去 收录申请 提交你想找的站"。为什么：把死路变出路（呼应产品方案的反馈入口，视觉先行）。

### 4.3 发展方向（中短期 1–3 个月 / 长期半年以上）

- **中短期**：① 上面 7 项视觉修复（都是 CSS 级小改动，一周内可清完）；② 把现有 CSS 变量整理成一份**设计 token 文档**（色板/字体阶/间距/圆角/阴影 + 亮暗对照表），作为后续所有改动的"视觉宪法"，防止新增页面跑偏；③ 配合产品方案做"本周上新"栏目的视觉原型（这是新的视觉组件，先把规格定清楚）。
- **长期**：① 若走"可信政务垂类"，做**品牌深化**：政务质感的 logo 强化（印章感）、庄重排版规范、证件照式规范化的卡片封面体系（外部图片太杂，统一封面模板），让"官方感"从视觉上彻底立住；② PWA 打磨：补齐 512px 图标与启动屏，把 manifest 的潜力用完；③ 建立设计 QA：每次改动跑一次对比度/焦点/暗色三查，防回潮。
