## 二、圆桌总结（综合之前所有答卷 + 自己的思考）

我通读了第 1–30 位。圆桌把"可信/非官方/合规/定位/增长/战略/顺序/用户侧沉淀/测量/内容/时效/相关性/聚合管道"说到极深，#30 更补上了"燃料从哪来"（构建期 CI 流水线 + 聚合≠生成守门红线）。**但整张圆桌漏了最关键的一层——管道之上、用户眼前那一层的"内容品控"：哪些算"热点"、每条怎么打"可信度分级"标签、怎么守"不传谣"、怎么"可溯源"地呈现**。我实地核验了站点，结论比想象更硬：

### ① 核心核验结论（实地，热门新闻聚合视角的铁证）

我查了 `index.html` 全站 grep + 目录结构 + 字段痕迹：

- **首页零热点资讯呈现、零信源标注、零可信分级**：`index.html` grep `热点/榜单/排行/资讯流/动态/信源/来源标注/待核实/可信度/分级/credibility/hot/trending/rumor` —— **唯一命中的是"结果计数""标签 chip"注释**，即站点**没有任何"变动速览/热点流/信源标注/可信度徽章"**，用户从首页看不出"活不活、哪条热、哪条真"。
- **内容区仍空转**：`news/journal/blog` 目录物理缺失（与 #27 互证），#30 流水线要生成的 `journal/` 也还没影子，"燃料"尚无落点。

- **#21 per-card 可信档案（来源/核验/失效）**：这是"可信"的数据底座；我补：**它必须"可见化"**——从后台档案变成用户一眼可见的「高/中/待核实」徽章（否则 #21 白做）。

### ③ 我补充的（热门新闻聚合专属，别人没说的——本棒核心）

1. **"热点"必须收敛为"影响你找对官方入口的变动情报"，不能做泛新闻门户**：热门新闻聚合专家的第一纪律是**先定义"什么算热点"**。对政务导航站，热点 ≠ 社会/科技/军事泛资讯（那会稀释"可信政务"品牌、踩 #15/#18 冒充/混淆雷、放大 #19 谣言面）；热点 = **官方入口/热线/政策/办事指南的"变动"**（新增、调整、失效、截止、改版）。这一收敛让"热点"与站点核心价值（找对官方入口）100% 对齐，且天然低风险（变动情报本就来自官方源）。
2. **「高/中/待核实」三级可信标注 = 把 #21 可信变"用户可见标签"**：本专家招牌。给每条变动情报打分级——**高**：官方源发布 + ≥2 独立源印证（接 #30 多源印证数）；**中**：单一官方源或权威媒体转载、暂未交叉印证；**待核实**：突发/网友报料/仅单一非官方源，**不进首页流、不弹推送、只挂"核查中"角标 + 原文链接**。这是把 #21 后台档案、#30 多源计数，**一次性织成用户一眼能判真假的视觉标签**——圆桌 30 棒从没人做这步"最后一百米"。
3. **"不传谣"硬纪律：待核实项零主动触达 + 误报熔断**：政务/民生变动消息是谣言高发区。硬规则：① **"待核实"类永不进首页流、永不通推（push/邮件/失效提醒）**，只在用户主动点进"变动情报"专页时可见，且置顶"核查中，以下非官方确认"；② 任一条发布后被标记失效/证伪，**立即降级 + 挂"已证伪"红标 + 原文链接**，并触发 #30 误报率计数；③ 误报率 > 5% 自动暂停自动流、转纯人工（接 #30 熔断 + #26"无分母不拍板"）。这是把 #19 舆情防御**从"出事再回应"前移到"发布前就不让谣言出门"**。
4. **"可溯源"呈现规范（本专家输出范式）：每条 = 标题（带原文链接）+ 来源 + 发布时间 + 核心要点 + 可信度分级**：严格按热门新闻聚合专家的输出规范，每条情报都必须带**原文链接（可溯源）+ 发布时间（可判时效）+ 可信度分级（可判真假）**。这正好 operationalize #21"可溯源" + #28"新鲜度" + 本棒"分级"，且让 #26 `source_click` 埋点有落点（用户点原文 = 真·溯源行为）。
5. **"热点"的"热度"定义要政务化，不能唯点击量**：#2/#20 早说 pageview 是虚荣指标。本棒定：**政务变动情报的热度 = 影响面（涉及多少用户/地区）× 时效性（距发布多久）× 多源印证数**，**不是点击量**。这既喂 #28 流排序、又避免把"最耸动的谣言"排最前（谣言往往最耸动），从排序层就压住 #19 风险。

### ④ 我反对的

- **反对把站点做成"泛新闻门户"**：上社会/科技/军事泛资讯 = 稀释"可信政务"品牌 + 踩 #15/#18 冒充/混淆 + 放大 #19 谣言面，是把圆桌 30 棒的可信地基自己挖掉。热点必须收敛为"官方入口变动情报"（本棒第 3 条）。
- **反对"聚合完直接上首页流"**：无分级、无"待核实"隔离 = 谣言直送用户眼前（#19 炸弹）。必须先分级、待核实不主动触达（本棒第 3 条）。
- **反对"可信只存后台档案、不示用户"**（轻反对 #21 现状）：#21 建了 per-card 可信档案却不可见 = 用户照样分不清真假，"可信"对用户是零。必须落到「高/中/待核实」可见徽章（本棒第 2 条）。
- **反对"热度唯点击量"**（轻反对 #2/#20 未被落实）：最耸动的往往最假，唯点击量排序 = 把谣言顶到最前。政务热度必须 = 影响面×时效×印证（本棒第 5 条）。

### ⑤ 往哪推一步

把"热门新闻聚合专家的「可溯源、不传谣、分级标注」纪律"落成**一条"变动情报分级标注 + 发布纪律"规范**，织进前位五棒：**① 把"热点"收敛为"影响找对官方入口的变动情报"**（不稀释品牌、不踩冒充/谣言雷）；**② 给每条打「高/中/待核实」徽章，把 #21 可信从后台档案变用户可见标签**（#30 多源印证数 → 徽章）；**③ 钉死"不传谣"：待核实零主动触达 + 证伪即降级挂红标 + 误报 >5% 熔断**（接 #30 守门 + #19 舆情前移）；**④ 每条按"标题+原文链接+来源+发布时间+核心要点+可信度"可溯源呈现**（接 #21/#28 + #26 `source_click`）；**⑤ 政务化热度（影响面×时效×印证）喂 #28 流 + #29"为你"排序**（先分级后相关，顺序不可反）；**⑥ 扩展 #26 埋点 `hot_view`/`hot_click`/`source_click` 验证"分级情报真驱动回访"**。这是把 #21 可信、#25 沉淀、#26 测量、#27 内容、#28 时效、#29 相关性、#30 聚合**七棒在"用户眼前那层品控"一次性织成"替你盯着、且每条都标信源不信口开河"的民生导航**——且全程纯静态、零后端、零 PIPL 个人信息风险。

## 三、专业深挖：我的 3 个问题及答案

> 注：这 3 个问题已同步追加到主问卷第 6 节「历届追加问题池」。

- **Q1. 政务导航站的"热点"到底指什么？怎么把"热点"从"泛社会新闻"收敛为"影响你找对官方入口的变动情报"（官方入口/热线/政策/办事指南的新增·调整·失效·截止·改版），避免稀释"可信政务"品牌、踩 #15/#18 冒充/混淆雷、放大 #19 谣言面？**
  - A1. **先给"热点"下政务化定义**：本站的"热点"= 收录卡（官方入口）及其关联政策/热线/办事指南的**状态变动事件**，五类——① 新增（新开官方入口）；② 调整（入口搬家/更名/合并）；③ 失效（关停/域名变更/仿冒预警）；④ 截止（补贴/申报/政策窗口期）；⑤ 改版（办事流程变更）。**绝不收"社会/科技/军事泛资讯"**——那是新闻门户的活，不是导航站的活，收了就稀释品牌、踩冒充/混淆雷（#15/#18）、放大谣言面（#19）。收敛后，"热点"与站点核心价值（找对官方入口）100% 对齐，且变动情报本就源自官方公告/RSS（#30 六源之一），天然低风险。呈现上单列"变动情报"区（不混官方入口卡、不混广告，#6/#15），标题即"XX 省 12345 热线于 2026-08 增设 XX 通道"这种"变动体"，用户一眼知"哪变了"。

- **Q2. 可信度分级怎么落到可执行的字段与 UI（高/中/待核实 + 原文链接 + 发布时间），让 #21 可信从"后台档案"变"用户一眼可见的标签"，且"待核实"项不主动推送/不进首页流（不传谣纪律）？**
  - A2. **字段 + UI 双落地**：① **数据字段**（接 #21 per-card + #30 多源印证数）：每条情报带 `credibility_tier`（high/mid/pending）、`source_url`（原文链接）、`published_at`（发布时间）、`source_count`（印证源数）、`corroborated_by`（印证源列表）；② **UI 徽章**：`高`=绿底"✔ 官方源·N 源印证"、`中`=黄底"单一官方源"、`待核实`=灰底"核查中·非官方确认"；③ **发布纪律（不传谣）**：`pending` 类**不进首页流、不通推（push/邮件/失效提醒 #28）**，只在用户主动进"变动情报"专页时可见、且置顶"以下非官方确认，请以官方为准"；④ **证伪即降级**：任一条发布后被标记失效/证伪，立即挂"已证伪"红标 + 原文链接，并计入 #30 误报率。这样 #21 的"可信"从"写给人看的后台档案"变成"用户一眼判真假的可见标签"，圆桌 30 棒从没人补这"最后一百米"。

- **Q3. 热点递送怎么既用 #26 埋点（hot_view/hot_click/source_click）验证"分级情报真驱动回访"、又守 #19 舆情（待核实误报熔断）、#6/#15 广告与政务内容隔离、不冒充官方（#15/#18/#19）？**
  - A3. **验证侧**：扩展 #26 事件 schema 加 `hot_view`（看了变动情报区）/ `hot_click`（点了某条情报）/ `source_click`（点了"原文链接"= 真·溯源行为），看板监控"分级情报 → 回访率""source_click → re-find 率"，无 30 天分母不判成败（#26 治理红线）。**合规侧**：① 变动情报区与 AdSense **区块隔离 + 文案标注"以下为官方来源情报/以下为广告"**（#6/#15 广告不混政务）；② 每条"来源：XX 官网 · 非本站发布 · 请以官方为准"（#15/#18 不冒充、#21 指路不代办）；③ **不传谣熔断**：`pending` 零主动触达 + 误报率 > 5% 自动暂停自动流转纯人工（接 #30 守门 + #19 舆情前移）。这样"分级热点"既闭环测量、又从发布前就把谣言挡在门外。

## 四、点评 / 修改方案 / 发展方向

### 4.1 点评（现状：好在哪、问题在哪）

**做得好（热门新闻聚合视角）**：
- 已有"红金白可信"品牌底座 + 分类筛选骨架——变动情报分级徽章可挂其上，不用重写；
- 圆桌已备齐"可信溯源（#21）+ 聚合管道（#30）+ 用户沉淀（#25）+ 指标（#26）+ 时效流（#28）+ 相关性（#29）"六块拼图，只差"**用户眼前那层品控：可信度分级标签 + 不传谣发布纪律 + 可溯源呈现**"。

**有问题（热门新闻聚合视角）**：
- 🔴 **零热点资讯呈现**：首页无任何"变动速览/热点流/信源标注/可信度徽章"（grep 实证）；
- 🔴 **"可信"不可见**：#21 per-card 档案只存后台、#30 多源印证数从未变成用户可见标签（圆桌 30 棒最大"最后一百米"缺口）；
- 🔴 **零"不传谣"机制**：无"待核实"隔离、无误报熔断，未来上热点即 #19 炸弹引信；
- 🟡 **"热点"定义缺失**：若乱上泛资讯 = 稀释品牌 + 踩冒充/谣言雷（本棒第 1 条要收敛）；
- 🟡 **热度定义缺失**：无"影响面×时效×印证"政务化热度，易把谣言顶最前（本棒第 5 条）；
- 🟡 **内容区仍空转**：`news/journal/blog` 物理缺失，#30 燃料无落点（与 #27 互证）。

### 4.2 修改方案（改哪里 → 改成什么样 → 为什么，标优先级）

- **[高] 把"热点"收敛为"官方入口变动情报"五类（新增/调整/失效/截止/改版），单设"变动情报"区**：不混官方入口卡、不混广告（#6/#15）。为什么：锚定站点核心价值、不稀释品牌、不踩 #15/#18/#19 雷（本棒核心收敛）。
- **[高] 每条打「高/中/待核实」可信徽章（接 #21 档案 + #30 多源印证数）**：字段 `credibility_tier`/`source_url`/`published_at`/`source_count` → UI 绿/黄/灰徽章。为什么：把 #21 可信从后台变用户可见标签，圆桌最大"最后一百米"。
- **[高] 钉死"不传谣"发布纪律：pending 零主动触达 + 证伪即降级挂红标 + 误报 >5% 熔断**：接 #30 守门 + #19 舆情前移。为什么：把谣言挡在发布前，是本站"可信"生命线的最后护栏。
- **[中] 每条按"标题+原文链接+来源+发布时间+核心要点+可信度"可溯源呈现**：接 #21/#28 + #26 `source_click`。为什么：本专家输出范式，让溯源可量化。
- **[中] 政务化热度（影响面×时效×印证）喂 #28 流 + #29"为你"排序（先分级后相关）**：为什么：解 #28 噪声 + #29 无排序，且压住谣言排序风险。
- **[中] 扩展 #26 埋点 `hot_view`/`hot_click`/`source_click` + 误报率看板**：接 #26 看板，验证"分级情报真驱动回访"且监控误报。为什么：本棒价值 + 安全可量化。
- **[低] 变动情报区与 AdSense 区块隔离 + "来源/非官方"标注**：接 #6/#15/#18。为什么：广告不混政务、不冒充官方。

### 4.3 发展方向（中短期 1–3 个月 / 长期半年以上）

- **中短期**：定义"变动情报"五类 + 建"变动情报"专页（S6 骨架，接 #27）→ 给 #30 流水线输出的每条打 `credibility_tier` 徽章 → "待核实"隔离 + 误报熔断上线 → #26 埋点 `hot_view`/`hot_click`/`source_click` 上线 + 误报率看板。目标：30 日内变动情报覆盖收录卡 `status` 变更 ≥ 80%、`高`级占比（多源印证）≥ 60%、`待核实`主动触达率 = 0%、误报率 < 5%、情报区浏览率 ≥ 活跃用户 15%（待 #26 30 天分母校准）。
- **长期**："收敛的热点 + 三级可信标注 + 不传谣纪律 + 可溯源呈现"成站点可信护城河（"每条变动都标信源、分级可见、待核实不扰民"），把 #21 可信、#25 沉淀、#26 数据、#27 内容、#28 时效、#29 相关性、#30 聚合在"用户眼前那层品控"织成"替你盯着信息、且每条都标信源不信口开河"的民生导航；误报熔断让"热点"永远在安全栏内，#19 伪数据/冒充官方舆情从设计上被排除；全程纯静态、零后端、零 PIPL 个人信息风险。
