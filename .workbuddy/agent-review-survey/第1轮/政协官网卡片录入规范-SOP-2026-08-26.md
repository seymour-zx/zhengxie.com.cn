# 政协官网卡片录入规范（SOP）

> 版本：v1.0 ｜ 日期：2026-08-26 ｜ 适用范围：正协导航"各级政协官网"收录（卡片类型 1）
> 本规范由圆桌第 21 位（可信办公）、第 24 位（公文审稿）结论落成。目标：让每张卡片长得一样、读不出歧义、来源可核验。

## 1. 卡片字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 是 | 见 §2 命名模板 |
| 描述 | 是 | 见 §3 描述模板 |
| 标签 | 是 | 见 §4 受控词表（两维度） |
| 链接 | 是 | 见 §5 链接规则 |
| 可信档案 | 是 | 见 §6 四要素 |

## 2. 名称（命名模板）

**模板：`{行政区划标准简称}{政协}`**，行政区划取 GB/T 2260 标准简称。

- 省级：`广东省政协` `新疆维吾尔自治区政协` `北京市政协`
- 市级：`深圳市政协` `广州市政协`
- 市辖区 / 县：必须带上级市名，`广州市天河区政协`（防重名歧义）
- **禁用**：精选 / 权威 / 官方推荐 / 最全 等绝对化词（#17 广告法红线）

## 3. 描述（描述模板）

> `{官方全称}官方网站。提供政协动态、会议提案、委员履职等信息。本站为第三方导航，与官方无隶属关系，不对跳转后内容负责。`

例：`中国人民政治协商会议广东省委员会官方网站。提供政协动态、会议提案、委员履职等信息。本站为第三方导航，与官方无隶属关系，不对跳转后内容负责。`

## 4. 标签（受控词表，两维度）

维度 1 · 地域（可多值，用全称）：`广东省` `广州市` `天河区`（"广东"仅作搜索别名，不进主标签）
维度 2 · 类型（固定取值）：`国家级政协` `省级政协` `直辖市政协` `自治区政协` `市级政协` `市辖区政协` `县级政协`

例：新疆 → `[新疆维吾尔自治区, 自治区政协]`；深圳 → `[广东省, 深圳市, 市级政协]`

## 5. 链接（链接规则）

- 链接标签统一：`访问官网`（全站一致，不写地名）
- 链接旁显式展示官方真实域名：`访问官网 · www.gdcppcc.gov.cn`（#21 可信档案要求，露真域名化解"像官方"误认）
- href = 官方站点 URL

## 6. 可信档案（四要素，每张卡必挂）

`来源类型=官方` ｜ `核验渠道=工信部备案 / 域名 whois / 官网公告` ｜ `核验日期=YYYY-MM` ｜ `失效机制=每季度复核，失效即标"待核验"`

## 7. 排序铁律（GB/T 2260 行政区划代码）

- 省级：按 2 位代码升序（省 / 直辖市 / 自治区被自然交织，无"谁优先"争议）
- 市级：省内按 4 位代码升序
- 市辖区 / 县：市内按 6 位代码升序（市辖区代码天然排在县之前，无需手工分块）
- 显示：省 → 市 → 区 / 县 三级分组，组内按代码
- 全国政协置顶；民主党派单列分组（见 §8）

## 8. 民主党派分组

单列"民主党派"，按惯例顺序：民革、民盟、民建、民进、农工党、致公党、九三学社、台盟。各中央委员会官网照 §2–§6 同模板录入。

## 9. 示例：广东省树

```
广东省政协（44）
├ 广州市政协（4401）
│  ├ 广州市越秀区政协（440104）
│  ├ 广州市天河区政协（440106）
│  └ 广州市番禺区政协（440113）
├ 深圳市政协（4403）
├ 珠海市政协（4404）
└ 佛山市政协（4406）
```

## 10. 校验清单（发布前）

- [ ] 名称符合模板、无绝对化词
- [ ] 描述含官方全称 + 免责句
- [ ] 标签两维度均取自受控词表
- [ ] 链接标签 = 访问官网 + 露真域名
- [ ] 可信档案四要素齐全
- [ ] 排序按 GB/T 2260 代码
