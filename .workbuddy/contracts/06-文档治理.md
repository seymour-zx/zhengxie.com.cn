> 定位：README.md 的**唯一权威编写规则**（含下回修改的校准清单）
> 来源：造物主第 9 步 P-C 拍板（2026-08-30 23:04）——「README 要展示纯手工流：告诉世人如何手工编辑 HTML，而不是告诉他们怎么修改 xlsx 和运行 py」
> 提炼自旧世界 CONVENTIONS.md（§1.6/§1.7/§1.8/§1.11）+ 旧 README 实际结构 + 05-开发规范漂移清单

## 一、README 是什么（定位）

- **公开层「唯一权威决策手册」**（仓库根，首读锚点：MEMORY 步骤 → README 公开层 → 契约解释层）
- 面向**「想自建同类导航站的人」**的**纯手工流教程**：教人手写 HTML 搭出同样效果的站
- **不教内部工作流**：xlsx 数据源、py 构建脚本、.workbuddy 治理层一律不出现

## 二、编写规则（7 条，改 README 必守）

1. **纯手工流**：开头明示「不需要任何构建工具或数据源文件，所有内容直接手写进 HTML」；全文教手写 HTML（head 必填/body 结构/卡片/页脚/字段），**禁止出现 xlsx、.py、merge、build 等内部自动化**
2. **零内部引用（公开暴露铁律）**：README 在 .workbuddy/ 外、仓库公开 → 不提 `.workbuddy/`、契约、消融台账、真实统计 ID、GitHub 用户路径
3. **目录树 = 手工视角**：只列手写文件（index/topics/pages/404/css/js/images/json/CNAME/robots/sitemap/ads/favicon）；**不列 assets/xlsx、assets/.build**
4. **章节结构**（固定 11 章）：开头（站名+slogan+新定位+纯手工流声明+第三方声明）/ 一设计语言 / 二站点结构 / 三页面骨架 / 四手写入门 / 五字段手工录入 / 六视觉规范 / 七交互说明 / 八SEO / 九统计广告（HTML 视角）/ 十部署（含上线检查清单）/ 十一FAQ
5. **内容与现状一致**：定位=「综合全品类导航/陈列馆」（非纯政协）；功能清单以当前站点为准（随机漫步/滚动按钮/声明条/外链规则）；**已拍板删除的功能不得出现**（如统计授权条）
6. **改规则改配置不改散落代码**：外链策略规则表放 README §七，实现集中（build link_attr）
7. **漂移即回改**：发现 README 与现状不符 → 回改 README（或现状）→ 记当日日志（旧世界漂移清单 M-5/M-7 教训）
