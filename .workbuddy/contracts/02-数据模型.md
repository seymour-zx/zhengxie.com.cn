## 一·B、xlsx 读取逻辑要求（build 健壮性规格，2026-08-30 拍板）

1. **保持读第一个 tab**
2. **自动识别表头行**（不硬编码行号）
3. **列乱序不影响**（按列名取值，不依赖列顺序）
4. **不受插入或追加额外列影响**（造物主自加备注列安全：按需取已知列名，忽略未知列）

## 一·C、数据维护工作流（2026-08-30 拍板，推翻旧 DEC-012）

- **cards-pages/ = 编辑源（造物主维护）**：首页.xlsx（/）、cards.gov.xlsx（topics/gov）、cards.search.xlsx（topics/search）——造物主**不直接改 cards.unified**，改这些源文件或**新建 xlsx**（新收集/新页面）
- **merge_cards.py = 合并工具**：读 cards-pages/ 所有 xlsx（第一个 tab，按列名合并，以首个文件表头为基准）→ 生成 `cards.unified.xlsx`
- **build 读 unified**：按行 `dir_path` 识别属于哪个 html
- **数据流**：`cards-pages/*.xlsx → merge_cards.py → cards.unified.xlsx → build_homeplus → html`
- 旧世界 DEC-012（cards-pages 违反唯一真值源待删）**作废**——新世界唯一"编辑源"= cards-pages，unified = 派生产物

## 二、页面字段字典（pages.unified.xlsx，含拼装引擎）

> 旧世界 6 列 + **拼装引擎字段**（D-16：广告位 / 统计 / 搜索框 / 导语全部 xlsx 控制）。

| # | 列名 | 含义 | 说明 |
|---|---|---|---|
| 1 | dir_path | 页面路径 | `/`、`topics/gov`、`topics/search`、`topics`（专题导航 hub）… |
| 2 | title | 页面标题 | → `<title>` + og:title + twitter:title + JSON-LD name（一处改全联动） |
| 3 | description | 页面描述 | → description + og:description + twitter:description + JSON-LD description |
| 4 | keywords | 关键词 | → meta keywords |
| 5 | channel_intro | 导语内容 | 内容列（须配合 `channel_intro_enabled` 开关） |
| 6 | channel_intro_enabled | 导语开关 | **True 且有内容才显示导语**；True 无内容 / 有内容非 True → 都关（AND 规则） |
| 7 | enabled | 页面启用 | 空 / 0 = 不生成该页 |
| 8 | ad_slots | 广告位 | **`1,3` 式**（逗号分隔广告位编号）；**空 = 该页零广告代码（meta 零 AdSense 残留）** |
| 9 | stat_ga4 | GA4 开关 | True = 注入 GA4 脚本；空 = 无 |
| 10 | stat_baidu | 百度统计开关 | True = 注入百度统计；空 = 无 |
| 11 | search_box | 搜索框开关 | True = 显示集合搜索框模块；空 = 无（**首页/搜索专题页也由 xlsx 决定，py 无页面特判**） |

**拼装原则（2026-08-30 拍板）**：**页面模块全部由 xlsx 决定，py 无页面特判**——不做"哪个页面该有什么"的硬编码（首页、搜索专题页等无特例）。

**联动规则**：AdSense 脚本 + preconnect 随 `ad_slots`（有广告位才注入）；GA4/百度 preconnect 随各自开关；搜索框随 `search_box`。

**命名说明（准确无歧义）**：`ad_slots`（广告位，造物主原话"1,3 表示"）、`stat_ga4` / `stat_baidu`（统计，一眼懂）、`search_box`（搜索框）、`channel_intro`（导语，已有）。

## 二、排序规则（与旧世界一致，2026-08-30 拍板）

1. **分类按钮顺序** = xlsx 分类名**首次出现顺序**（造物主手工排分类行位置）
2. **卡片排序** = 先按 `card_layout`（type 1→2→3，不同类型强制分行），**组内按 `row_seq` 数值从小到大**
3. 造物主手工控制 = 手动维护 row_seq 数值 + 分类行位置；**py 不重排、不自动编号**
4. `card_order`：与旧世界一致——字段保留但**不参与渲染**（预留）
