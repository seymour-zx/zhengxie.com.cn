## 三、源码/产物位置（B 定案，2026-08-30）

**数据 xlsx + 构建脚本放 assets/**（沿用旧世界）：
- `assets/xlsx/`：cards.unified.xlsx + pages.unified.xlsx（数据真值源）
- `assets/.build/`：build.py / build_homeplus.py / check_links.py / verify_site.py + `reports/`（verify 报告 / link_report）
- assets 中 css/js/images/json = 公开；xlsx/.build = 存在但不易被看到（造物主接受此可见性）

**独立小世界愿景（核心理由）**：
- 新世界完善/不再改造 → **除 .workbuddy 外全部可剥离** → 独立小世界自己运行（改 xlsx + 跑 py 刷新）
- 或复制给其他造物主 → 除 .workbuddy 外全部复制
- **assets/ = 世界可运行本体**（数据+构建+产物自包含）；**.workbuddy = 内部治理**（剥离时不带走）

**约束**：
- verify 报告 → `assets/.build/reports/`
- feedback 台账 + 上线检查记录 → `.workbuddy/memory/`（内部运营记录，剥离时不带走）
- 坐标保护仍适用：assets/ 公开层零坐标
