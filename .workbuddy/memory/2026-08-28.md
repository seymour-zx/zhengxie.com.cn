## scope 归一化卫哨 _normalize_scope（13:0x 起）
- **背景**：用户问 5 种 scope 写法（directory/gov、/directory/gov/、/directory/gov、directory/gov/、//directory///gov//）是否等同。实测当前代码用原始字符串处理：①`os.path.join(BASE_DIR, scope)` 遇前导 "/" 视为绝对路径→丢弃 BASE_DIR→写到项目外；②canonical 拼接产生双斜杠畸形 URL；③行匹配精确比较→尾斜杠不匹配。仅 depth（资源前缀）因 split+过滤能抗多余斜杠。结论：不等价，需加载时归一化。
- **用户拍板 4 条规则**：①空值/哨兵(none/null/nil/na/n-a/nan)→跳过；②归一化仅去首尾斜杠→干净相对路径，**不折叠内部 //**；③拒绝非法：含 `..` 穿越/非法文件名字符/Windows 保留名；④安全网：归一化后拼 BASE_DIR 必须仍在项目内(否则跳过)。
- **实现**：在 `_merge_meta` 之后新增 `_normalize_scope(raw)` + 常量 `_EMPTY_SCOPE_SENTINELS`/`_WIN_RESERVED`/`_ILLEGAL_NAME_CHARS`（标准 Windows 非法集 `<>:"\\|?*`，不含 "/" 因作分隔符）；安全网用 `os.path.commonpath` 比对，跨盘 ValueError 兜底拒绝。特例：根 `/` 去首尾斜杠会变空→特判保留为 "/"，否则根页元信息丢失（已向用户披露此必要偏差）。
- **接入**：`load_rows`（逐行归一化 scope、None 跳过、查询 scope 也归一化）、`load_meta`（行与查询均归一化）、`list_directory_pages`（逐行归一化，None/根 跳过）三处。
- **验证**：单元 15 例全过（根保留、5 变体正确归一化、空/哨兵/`..`/保留名/非法字符/跨盘 全部 None）；全量 `build.py` 三页 HTML 与基线**逐字节一致**（94007/88532/95720 B），零回归。
