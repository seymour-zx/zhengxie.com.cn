# 2026-08-29 工作日志

## 卡片链接行塌陷修复（A 方案，纯 CSS）
- 现象：`.card__links` 容器空时无 `min-height`，高度塌成 ~0，无链接卡片底部上缩、与同排有链接卡不齐。
- 决策：用户确认选 **A**（只加占位，不动 grid 拉伸）；并明确"链接行恒为单行（flex nowrap），链接条数不同不会导致行高变化" → 只需 min-height。
- 改动：`assets/css/style.css` L505-506 新增 `.card__links { min-height: 28px; }`（≈一条链接按钮高+padding）。纯 CSS、无需重跑 build（HTML 仍引同款 style.css）。
- 结论：无链接卡片链接行占位不塌；有链接卡行高 = 单行；同排卡片底部一致。
