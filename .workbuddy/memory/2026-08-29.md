## 卡片链接行塌陷修复（A 方案，纯 CSS）
- 现象：`.card__links` 容器空时无 `min-height`，高度塌成 ~0，无链接卡片底部上缩、与同排有链接卡不齐。
- 决策：用户确认选 **A**（只加占位，不动 grid 拉伸）；并明确"链接行恒为单行（flex nowrap），链接条数不同不会导致行高变化" → 只需 min-height。
- 改动：`assets/css/style.css` L505-506 新增 `.card__links { min-height: 28px; }`（≈一条链接按钮高+padding）。纯 CSS、无需重跑 build（HTML 仍引同款 style.css）。
- 结论：无链接卡片链接行占位不塌；有链接卡行高 = 单行；同排卡片底部一致。

## 筛选变更复位卡片名称/描述默认折叠（main.js）
- 需求：切换分类、点击内部搜索框、切换收藏展示、增/减标签筛选（含清除）时，卡片名称与描述展示恢复初始默认（不再保留点击展开的整行联动展开态）。
- 机制：所有筛选事件最终走 `applyFilter()`；卡片展开态由 `is-expanded` + `--lines`/`--title-lines` 内联变量控制，原 applyFilter 不复位 → 换筛选后已展开卡仍展开、高低不齐。
- 改动1：`applyFilter()` 末尾加 `resetExpandCollapsed()`（已有函数，把全部 t1/t2/t3 卡标题/描述收回到默认折叠：t1 标题2行/t2/t3 标题1行/描述1行），随后 refreshScrollable() 复检溢出（复位后宽度可能变）。
- 改动2：`siteInput` 加 `focus` 监听 `resetExpandCollapsed`，覆盖"纯点击搜索框未输入"场景。
- 校验：`node --check` 通过。其余进入 applyFilter 的路径（切分类/搜索输入/回车加标签/标签删除/清除/收藏开关/星标切换/hashchange）均一并复位，视图一致。
