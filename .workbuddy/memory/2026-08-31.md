# 2026-08-31 前端流畅性修复（main.js + pages CSS 版本对齐）

## 做了什么
对 `assets/js/main.js` 做了三处针对性修复，解决「点击按钮无反应 / 滑道滑不动」：

1. **wheel 滚动劫持边界修复**（主因·滑道滑不动）
   - 旧：全局 wheel 监听对 `is-scrollable` 滑道**无条件** `e.preventDefault()`，即使滑道已到横向边界，也吞掉竖向滚轮 → 鼠标悬停分类/标签滑道时整页无法上下滚。
   - 新：仅在滑道可朝滚动方向继续横滑时才劫持；到边界则交还页面。同时支持 trackpad `deltaX` 横向手势。

2. **移除滚动按钮全局输入锁**（主因·点击后卡死）
   - 旧：`返回顶部`4 按钮点击后 `lockUserInput()` 全局 `preventDefault` 拦截 wheel/touchmove/keydown 最长 8s；若滚动几乎不动，解锁要等满 8s → 页面“冻结”感。
   - 新：删除 `clickLock/lockUserInput/forceUnlock/pendingUnlock/__zxScrollUnlockTimer`；点击只做 `safeScrollTo`+`showTarget`，位置同步交给 scroll 事件 `syncScroll` 自然完成。**无任何锁可死**。T6 的 smooth→two-arg 降级保留（qa-scroll-check 双场景仍通过）。

3. **新增桌面拖拽横向滚动**（满足 .track 的 grab/grabbing 光标语义）
   - 单例管理（仅 3 个 document 级监听），作用于 `is-scrollable` 的 `.track`/`.card__tags`/`.card__links`；触屏仍走原生 pan-x。
   - 拖动 >6px 才视为拖拽并抑制本次 click，避免误点分类/标签/链接。
