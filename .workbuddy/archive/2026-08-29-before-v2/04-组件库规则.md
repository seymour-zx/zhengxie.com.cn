# 正协导航 · 组件库规则（04-组件库规则）

> 读者：改 HTML 结构、加卡片、加页面前必读。
> 版本：v1.0 ｜ 2026-08-29 ｜ 真值源 = `index.html` / `directory/*/index.html` 实际结构 + `assets/css/style.css`
> 前提：本项目**无前端框架**（ADR-006），组件复用靠 HTML 模板 + class 契约。因此**契约就是法律**——没有类型检查兜底，写错只能靠本文档与测试。

---

## 1. 命名规范

采用 BEM 变体：`block__element--modifier`，全小写，词间 `-`。

| 层级 | 写法 | 实例 |
|---|---|---|
| 块 | `block` | `card`、`hero`、`footer` |
| 元素 | `block__element` | `card__title`、`hero__logo` |
| 修饰符 | `block--modifier` / `block__element--modifier` | `card--t1`、`card__tag--cat` |
| 状态类 | `is-*`（JS 加/删） | `is-scrollable`、`active` |
| 数据属性 | `data-*`（JS 读） | `data-cat`、`data-tag`、`data-key` |

**禁止**：`is-*` 用于静态样式、`data-*` 用于样式选择器、大写或驼峰 class。

## 2. 组件总清单

### 2.1 页面级组件（S1 导航产品页骨架）

按 `<body>` 自上而下 8 块，**顺序不可调换**：

| 序 | 组件 | class | 说明 |
|---|---|---|---|
| 0 | 跳转链接 | `.skip-link` | 无障碍：跳到主内容，视觉隐藏、聚焦可见 |
| 1 | 首屏 | `.hero` > `.hero__logo` + `.hero__slogan` | 大 Logo + slogan + 集合搜索（主引擎按钮 + 搜索框 + 引擎滑道） |
| 1.5 | 频道导语 | `.channel-intro` > `.channel-intro__desc` | 频道页专属（D1 内容化目标位） |
| 2 | 顶部广告位 | `.ad.ad--top` > `.ad__label` + `.adsbygoogle` | 容器左右零留白，只保留上下间距 |
| 3 | **吸顶区** | `.sticky-top` | **包住序号 4–6 三块**，整体 sticky |
| 4 | 分类导航 | `.category-nav` | 左方形文字 Logo（=「全部」）+ 中滑道 `.track` + 右「本地收藏」 |
| 5 | 站内搜索 | `.site-search` | 实时筛选 + 回车固化为标签 |
| 6 | 结果计数 | `.result-count` > `.result-count__text` | 见 §4.3 文案规则 |
| 7 | 卡片容器 | `.cards-container` | Grid 直接装全部卡片 |
| 8 | 底部广告位 | `.ad.ad--bottom` | 同 2 |
| 9 | 页脚 | `.footer` | 见 §4.5 |

> 6（结果计数）与「筛选标签行」同属吸顶区；筛选行结构：`.filter-tags` > `.filter-tags__hint` + `.filter-tags__track` + `.filter-tag__clear`。

### 2.2 卡片级组件

| 元素 | class | 必填 | 说明 |
|---|---|---|---|
| 根 | `.card.card--t1` / `--t2` / `--t3` | ✅ | 用 `<article>`；带 `data-cat="分类名"` |
| 媒体 | `.card__media` > `.card__media-img` | ✅（占位） | WebP + 透明通道；`loading="lazy" decoding="async" referrerpolicy="no-referrer"` |
| 媒体兜底 | `.card__media-fallback` | 可选 | 图片加载失败时露出文字 logo 占位 |
| 标题 | `.card__title` 用 `<h3>` | ✅ | 站点名；超长截断（B7 待做两行截断） |
| 收藏 | `.card__fav` 用 `<button>` | ✅ | `data-key`（唯一键）+ `aria-label` + `aria-pressed` |
| 描述 | `.card__desc` | ✅（空也占位） | 一句话 |
| 标签行 | `.card__tags` > `.card__tag` | ✅（空也占位） | **第 1 个标签固定为分类名**，带 `.card__tag--cat` |
| 链接行 | `.card__links` > `.card__link` | ✅（空也占位） | 外链属性按 ADR-008 |
| 链接箭头 | `.card__link-arrow` | 装饰 | `aria-hidden="true"` |
| 分组换行 | `.grid-break` | 自动 | **type 之间强制换行**，不同类型绝不同行 |

### 2.3 交互级组件

| 组件 | class | 行为契约 |
|---|---|---|
| 滑道 | `.track` | 仅内容真溢出时，悬停高亮 + 滚轮接管为左右滑（页面暂停上下滚）；触屏触摸同样激活 |
| 收藏按钮 | `.card__fav` | 内联 SVG 星形 `<use href="#zx-fav-star">`；CSS 按 `aria-pressed` 切换描边/填充 |
| 本地收藏开关 | `.category-nav__fav` | 切换"只显示已收藏" |
| 空状态 | `.empty-state` > `.empty-state__icon` + `.empty-state__text` | 只显示提示文案，**不设"清除所有筛选"按钮** |
| 主题切换 | `.theme-toggle` > `__sun` / `__moon` | 固定页脚工具簇，不进吸顶区 |
| 随机漫步 | `.footer__random` | 页脚工具簇 |
| 滚动按钮 | `.scroll-btn--up/--top/--down/--bottom` | 页脚工具簇 |

## 3. 卡片三种 type 契约

| type | 网格 | 媒体区比例 | class |
|---|---|---|---|
| **1** | 4 行 3 列（图片跨两行） | logo 方形 | `card--t1` |
| **2** | 5 行 2 列（封面跨两列） | 横向 `1.618/1`（黄金比） | `card--t2` |
| **3** | 5 行 2 列（同 t2） | 纵向 `1/1.618` | `card--t3` |

**通用约束（三类一致，违反即 bug）**：

1. 名称、描述、标签、链接**必有**（空也占位），各占一行，超出截断或横向滚动。
2. 卡片内所有内容**允许框选/复制**（不得设 `user-select:none`）。
3. 标签行第 1 个标签 = 该卡片的**分类名**。
4. 三种 type **按 type 分组分行**（t1 组 → t2 组 → t3 组，组间 `.grid-break` 强制换行），**不同类型绝不同行**。
5. 排序：**先按 type（1→2→3）分组，再按站序从小到大**；站序只在同 type 内部生效。

### 3.1 卡片 HTML 模板（可直接复制）

```html
<article class="card card--t1" data-cat="分类名">
  <div class="card__media">
    <img class="card__media-img" src="图片URL" alt="站点名"
         loading="lazy" decoding="async" referrerpolicy="no-referrer"
         onerror="this.remove()">
  </div>
  <h3 class="card__title">站点名</h3>
  <button type="button" class="card__fav" data-key="唯一键（一般用主域名）"
          aria-label="收藏/取消收藏" aria-pressed="false">
    <svg aria-hidden="true" focusable="false"><use href="#zx-fav-star"></use></svg>
  </button>
  <p class="card__desc">一句话描述</p>
  <div class="card__tags">
    <button type="button" class="card__tag card__tag--cat" data-tag="分类名">分类名</button>
    <button type="button" class="card__tag" data-tag="标签">标签</button>
  </div>
  <div class="card__links">
    <a class="card__link" href="https://目标域名" target="_blank"
       rel="noopener" referrerpolicy="origin">访问官网 - 目标域名<span class="card__link-arrow" aria-hidden="true">↗</span></a>
  </div>
</article>
```

> 卡片由 build 脚本从 xlsx 生成时，**不要手改生成结果**——改数据源重跑 build（ADR-002）。
> 手写页（`pages/*`）中的卡片才按本模板手写。

## 4. 关键行为契约（写错即缺陷）

### 4.1 三维度筛选（AND 叠加）

`分类（activeCat）` × `关键词（filterTags）` × `本地收藏（showFav）` —— **三者同时满足才显示**。

| 交互 | 效果 |
|---|---|
| 点 Logo | 重置分类为「全部」（只动分类） |
| 点分类按钮 | 只显示该分类 |
| 搜索框输入 | 实时筛选 |
| 回车 | 固化为筛选标签 |
| 点卡片内文字标签 | 等同一次站内搜索；多标签叠加（AND） |
| 点星形 | 收藏/取消收藏 |
| 点顶部「本地收藏」 | 切换"只显示已收藏" |
| 点「清除筛选」 | **只清关键词**，不影响分类与收藏 |

### 4.2 统一滑动行为

所有滑道（分类/标签/链接）与卡片四类行（title/desc/tags/links）共用一套：

- 仅在**内容真溢出**时接管滚轮为左右滑，页面暂停上下滚；不溢出时滚轮照常滚页面。
- 触屏触摸同样激活。
- 溢出时加 `is-scrollable`（金色高亮描边）。

### 4.3 结果计数文案（三种形态）

| 场景 | 文案 |
|---|---|
| 无筛选 | `共 N 张卡片` |
| 任一维度生效 | `当前显示 X / N 张卡片` |
| 0 结果 | 红色加粗提醒 + `.empty-state` 提示文案 |

### 4.4 集合搜索（Hero）

百度 / Google / 必应为首引擎按钮，下方引擎滑道含淘宝/京东/知乎/B站/GitHub 等。点引擎激活，回车**新窗口**打开结果页。

### 4.5 页脚契约

`.footer` 必含三块：

1. `.footer__copyright` —— 版权 + 备案号占位（**有 ICP 备案才渲染**，未备案前不渲染但代码保留）。
2. `.footer__nav` —— 统一导航链接，**必含「网站全景」「频道导航」**。
3. `.footer__tools` —— 工具簇：随机漫步（`.footer__random`）+ 暗色切换（`.theme-toggle`）。

## 5. 变体与状态清单

| 组件 | 状态类 | 触发 |
|---|---|---|
| 分类按钮 | `.active` | 当前选中分类 |
| 卡片 | `.is-scrollable` | 内容溢出（JS 检测） |
| 卡片标题/描述/标签行/链接行 | `.is-scrollable` | 同上，四类行各自判定 |
| 收藏按钮 | `aria-pressed="true"` | 已收藏（CSS 据此填充金色） |
| 根 | `data-theme="dark"` | 用户手动切换主题 |

---

## 6. 新增组件流程

1. 先查 §2 清单——**能复用就复用**，不新增。
2. 确需新增：定 BEM 名 → 写进 `assets/css/style.css`（token 只能用 §03-设计规范 已有变量，新增 token 先改 03）→ 在本文件 §2 登记 → 写用例（09-用例模板）。
3. 组件若带交互：JS 写在 `assets/js/main.js`，事件委托优先，不新增内联 `on*` 属性（现有 `onerror="this.remove()"` 为历史遗留，新代码不得新增）。

---

## 7. 反模式（禁止）

- ❌ 手写自造 class 而不登记（如 `my-card`）。
- ❌ 在卡片上设 `user-select:none`。
- ❌ 分类按钮加计数徽章。
- ❌ 空状态加"清除所有筛选"按钮。
- ❌ 暗色切换放进吸顶区。
- ❌ 不同类型卡片混在同一行（缺 `.grid-break`）。
- ❌ 新增内联 `on*` 事件处理器（阻碍 CSP 落地，见 11-安全审计）。
- ❌ 直接手改 build 生成的 HTML。
