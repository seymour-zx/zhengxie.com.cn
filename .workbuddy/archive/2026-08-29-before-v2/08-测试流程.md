## 3. L1 静态扫描（自动化，可脚本化）

> 以下 8 项即 `assets/.build/verify_site.py` 的验收范围（2026-08-29 按 M-1 方案甲落地，`python assets/.build/verify_site.py` 一键执行；红线失败退出码 2、严重项 1、全过 0）。

| # | 检查项 | 判定 | 2026-08-29 实测 |
|---|---|---|---|
| **1** | **相对资源路径断链** | 所有 `href`/`src` 相对路径指向的文件必须存在，零 404 | ✅ 0 处（2026-08-29 修复 P0-1） |
| **2** | head 标签齐备 | `title` / `description` / `keywords` / `canonical` / `og:title` / `og:description` / `og:image` / `og:site_name` / `og:url` / `twitter:card` / `theme-color` / `viewport` | ✅ 14/14 齐全（2026-08-29 批量补齐 11 页；404 页豁免 canonical——404 不应被索引，加 canonical 会误导搜索引擎） |
| **3** | 外链属性 | `target="_blank"` 必带 `noopener`；`rel` 符合域名优先级 | ✅ 207 处 `_blank`，**0 处缺 `noopener`** |
| **4** | 链接目标合法性 | 无裸 IP 外链、无 `http://`（优先 https）、无空 `href` | ✅ 0 项未登记问题；3 项已知豁免进整改清单（裸 IP 政务站 1 处；cppcc/cndca 未启用 https，2026-08-29 实测） |
| **5** | 图片 | 每个 `<img>` 必带 `alt`；`loading="lazy"`；外链图 `referrerpolicy="no-referrer"` | ✅ 9/9 有 alt |
| **6** | 标题层级 | 每页 `h1` 唯一且为站点名；`h2`/`h3` 层级连续不跳级 | ✅ 根页 h1×1 / h2×11 / h3×337 |
| **7** | JSON-LD | 存在且 `@type` 符合 CONVENTIONS §3.1 映射；JSON 可解析 | ✅ 13/14 页有（404 无，符合预期） |
| **8** | 面包屑 | 层级真实、与可见导航一致、末级为当前页 | ✅ 12 页有 BreadcrumbList |

### 3.1 可复用扫描片段（相对路径断链）

```python
import re, os
for pg in PAGES:                       # 所有 html 相对仓库根路径
    html = open(pg, encoding='utf-8', errors='ignore').read()
    for attr in ('href', 'src'):
        for u in re.findall(r'%s="([^"]+)"' % attr, html):
            if u.startswith(('http', '#', 'mailto:', 'data:', 'javascript:')):
                continue
            if not os.path.exists(os.path.normpath(
                    os.path.join(ROOT, os.path.dirname(pg), u))):
                print('断链:', pg, '->', u)
```

## 4. L2 构建校验

```bash
python assets/.build/build.py
echo "exit=$?"   # 必须为 0
```

必查：

- 退出码 0（非 0 即中断，禁止"表面成功"）。
- 根页 + **全部**频道页均已重新生成（不接受只生成一部分）。
- 表头含中文旧键 → build 应报错拒绝（不是静默跳过）。
- 生成产物体积未异常膨胀（对比 14-性能基线预算）。

## 6. L4 浏览器手工核验（发布前必做）

### 6.1 功能（S1 导航产品页）

- [ ] 卡片按 type 分组分行（不同类型不同行，`.grid-break` 生效）
- [ ] 点 Logo = 重置「全部」；点分类按钮 = 只显示该分类
- [ ] 站内搜索实时筛选；回车固化为标签；多标签 AND 叠加
- [ ] 点卡片内文字标签 = 一次站内搜索
- [ ] 收藏：点星形（描边金 → 填充金）；点顶部「本地收藏」只显示已收藏
- [ ] 「清除筛选」只清关键词，不影响分类与收藏
- [ ] 结果计数：无筛选「共 N 张卡片」；筛选后「当前显示 X / N」；0 结果红色加粗 + 空状态提示（**无"清除所有筛选"按钮**）
- [ ] 集合搜索：切换引擎，回车新窗口打开对应结果页
- [ ] 滑道：内容溢出时悬停高亮 + 滚轮转左右滑（页面暂停）；不溢出时滚轮照常
- [ ] 刷新后收藏与主题保持（localStorage）

### 6.2 视觉

- [ ] 响应式：手机 2 卡 / 平板 3 卡 / 桌面 4 卡
- [ ] **亮色 + 暗色各过一遍**（暗色不得偏蓝紫、无廉价渐变）
- [ ] 字体跨浏览器一致（`html` 16px + `text-size-adjust:100%` + 表单 `font-family:inherit` 未被删）
- [ ] 左 Logo 为**方形**（非圆形）、未选中淡红底、选中正红 + 金环
- [ ] 分类按钮**无计数徽章**；暗色切换在**页脚**（不在吸顶区）
- [ ] 卡片文本可框选/复制
- [ ] 媒体图加载失败 → 文字 logo 占位，不破版

### 6.3 无障碍

- [ ] Tab 键可遍历全部交互元素，焦点环可见（`:focus-visible`）
- [ ] 纯图标按钮有 `aria-label`（收藏按钮、主题切换）
- [ ] 图片有 `alt`
- [ ] 表单控件有关联 label
- [ ] 亮/暗两色下正文对比度 ≥ 4.5:1

### 6.4 禁用 JS 降级（SEO 生命线）

- [ ] 关闭浏览器 JS → 所有卡片、链接、分类按钮**仍然渲染且可点击**
- [ ] 页面内容完整可读（不依赖 JS 注入）

## 7. SEO 专项（新增/改动页面时）

- [ ] `canonical` 指向自身绝对 URL（build 自动生成，不得手改）
- [ ] `sitemap.xml` **手动补**（build 自动生成未授权，CONVENTIONS §5.5）
- [ ] JSON-LD `@type` 符合映射表；`isPartOf` 回链站点根
- [ ] 面包屑与可见导航一致，无虚构层级
- [ ] 内链绝对路径 + `target="_self"`
- [ ] 频道页导语为**独特内容**（非模板重复）
- [ ] 无重复标题/描述（sitemap 内页对比）
