## 0. ⚠️ AI 边界声明（先读这段）

依据 CONVENTIONS §二「专家转介纪律」：

- ✅ **AI 可做**：维护本清单、检查项是否落实、如实把技术实现写进隐私/免责**草稿**并置顶"AI 辅助、非执业律师意见"声明。
- ❌ **AI 不得做**：生成"看起来合规"的法条文并声称达标、给出法律合规结论、代办备案行政流程。
- ⚠️ **触发即停**：涉及隐私政策/免责声明/个保法条文/备案实操的**实质性判断** → 先说"这项需咨询法律类专家，我不替你下结论"，再视需要提供技术实现草稿供专家复核。

**本清单的每一项结论，凡涉及法律效力，均需人工或专家复核后方可认定"合规"。**

## 2. 发布前合规检查（每次发布逐项勾）

### 2.1 身份与声明

- [ ] **非官方声明可见**：站点不暗示与任何政府机构存在隶属关系
- [ ] **不使用政协官方标识/视觉风格**，不自称官方
- [ ] 免责声明页可访问且为最新版本
- [ ] 隐私政策页可访问，且**如实披露**当前实际接入的统计/广告（当前：百度统计 + GA4 + AdSense）

> ⚠️ 若 D-4 拍板删除 GA4/AdSense，**必须同步更新隐私政策**（否则披露与实际不符）。

### 2.2 备案与地域

- [ ] 备案号：有 ICP 备案才渲染；未备案前**不渲染但代码保留占位**
- [ ] 备案号链接指向 `beian.miit.gov.cn`（当前 12 处引用）
- [ ] 若启用国内托管/CDN → 备案先行

### 2.3 广告合规

- [ ] 政务 / 机构 / 办事频道页**零广告**（🔴 红线）
- [ ] 每个广告位有可见的「广告」小字标签（`.ad__label`）
- [ ] 广告容器左右零 margin/padding、无包裹样式（不误导为站内内容）
- [ ] 屏蔽代办 / 贷款 / 下载器类广告（F5）
- [ ] **404 页不放广告**（README §九）

### 2.4 内容红线（🔴 一票否决）

- [ ] 无 AI 自动生成的政务/民生资讯（聚合 ≠ 生成）
- [ ] 无"代办 / 代开 / 加急 / 包过 / 贷款 / 下载器"等负面词（D4）
- [ ] 无未经核实的民生求助信息（C5 最严核验档）
- [ ] 无转载未授权的正文内容

### 2.5 收录合规

- [ ] 新增收录 100% 过官方源核实（09-用例模板 UC-N01）：ICP 备案 + 域名归属 + 诈骗预警 + HTTPS 可达
- [ ] 台账已登记 `verify_date` / `verify_channel` / `status`
- [ ] 无裸 IP / 明文 http 的不可信外链

### 2.6 数据与技术

- [ ] 无越权采集（当前无后端、`localStorage` 仅存主题与收藏）
- [ ] 表单若有收集 → 明示用途并获同意；**确认提交内容有实际接收端**（见 11-安全审计 S-3）
- [ ] `robots.txt` 与 `sitemap.xml` 与实际结构一致

## 3. 收录核验标准（最严档）

> 来源：CONVENTIONS §5.5 🔴-3「禁止收录未核验链接」。

| 核验项 | 方法 | 不通过处置 |
|---|---|---|
| ICP 备案 | beian.miit.gov.cn 查询 | **驳回** |
| 域名归属主体 | whois / 备案主体比对站点名称 | 不一致 → 人工复核，无法确认则驳回 |
| 诈骗预警 | 12321 / 12377 等黑名单查询 | **驳回** |
| HTTPS 可达性 | 浏览器访问 + 证书有效性 | 不可用 → 驳回或标记待观察 |
| 内容性质 | 是否为官网（非商业代理/仿站） | 疑似代理 → 驳回 |

**民生求助类（热线/心理援助/法律热线）适用最严档（C5）**：额外要求官方来源可追溯 + 季度复核（CONVENTIONS §5.3.7）。

## 4. 内容红线（禁止清单）

| 类别 | 禁止内容 |
|---|---|
| **身份** | 暗示官方隶属、使用政协官方标识、自称官方 |
| **生成** | AI 自动写/自动发站内政务或民生资讯 |
| **负面词** | 代办 / 代开 / 加急 / 包过 / 贷款 / 下载器 |
| **广告** | 政务/机构/办事频道页放广告；屏蔽类广告未屏蔽；404 页放广告 |
| **收录** | 未核验链接；裸 IP / 明文 http 不可信外链 |
| **版权** | 未授权转载正文 |

> 不传谣发布纪律（#31 建成后适用）：待核实（pending）零主动触达；证伪即降级挂红标；误报 > 5% 熔断。

## 5. 定期复核节奏

| 周期 | 动作 | 依据 |
|---|---|---|
| **每次发布内容** | 过 §2 清单 + 公文审稿闸门（措辞/角标/来源留痕） | CONVENTIONS §5.3.2 第 8 步 |
| **每月** | 收录质量抽检：本月新增卡抽查核验 | §5.3.6 |
| **每季度** | 外链全量核验（备案/诈骗预警/域名归属）+ 民生热线信息核验 + 域名/备案/DNS 状态 | §5.3.7 |
| **每半年** | 站点架构复盘 + 定向专家评审 | §5.3.8 |

## 6. 必须转专家的事项（不得自行定稿）

| 事项 | 应咨询 |
|---|---|
| 隐私政策 / 免责声明 / 个保法条文 | 法律类专家（`北大法宝` / `同花顺法律AI助手` / `华宇元典` 等）或执业律师 |
| ICP 备案实操 / 国内服务器迁移 | 域名服务商（阿里云/腾讯云）官方备案通道 |
| 广告政策与变现合规 | Google AdSense 官方帮助中心 / 投放类专家 |
| 政务信息准确性 | 官方来源核实（深度研究专家） |

> 触发即停：AI 先声明"需咨询 X 专家，我不替你下结论"，仅可提供技术实现草稿供专家复核。

## 7. 合规事件处置

发现疑似违规（收到投诉 / 发现山寨链接 / 内容被指不实）：

1. **立即降级或下架**涉事内容（存疑即下架，不等核实完）。
2. 记录事件到当日时间日志 + 台账 `status` 字段。
3. 涉及法律判断 → 转专家（§6）。
4. 复盘：是核验流程哪个环节漏了 → 更新本清单或 16-内容更新规范。
