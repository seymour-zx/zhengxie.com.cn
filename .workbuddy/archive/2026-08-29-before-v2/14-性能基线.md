# 正协导航 · 性能基线（14-性能基线）

> 读者：每次部署前后、做性能优化时必读。
> 版本：v1.0 ｜ **2026-08-29 首次实测**
> 关键结论：**源文件体积大 ≠ 传输慢**。本站 HTML 高度重复，gzip 压缩率 5.7%，真实瓶颈是第三方脚本与 DOM 规模，不是文件体积。

---

## 1. 度量口径（先统一，否则数字没有意义）

| 口径 | 定义 | 为什么重要 |
|---|---|---|
| **源文件体积（raw）** | 磁盘字节数 | 影响仓库体积、HTML 解析耗时 |
| **传输体积（gzip）** | 经 gzip 后的字节数 | **影响实际下载时间**；GitHub Pages 对文本资源自动 gzip |
| **运行时成本** | DOM 节点数、JS 遍历范围 | 影响渲染与交互流畅度，与文件体积弱相关 |
| **核心指标** | LCP / CLS / TTFB | 用户可感知体验的最终判据 |

> 度量命令见 §7。**禁止只报 raw 不报 gzip**（会得出错误结论）。

## 4. 真实瓶颈分析（按影响排序）

### 🥇 瓶颈 1：第三方脚本（被墙导致超时，影响最大）

| 域名 | 引用 | 国内可达性 | 影响 |
|---|---|---|---|
| `www.googletagmanager.com` | 11 处 / 7 页 | ❌ 被 GFW 屏蔽 | 请求挂起直到超时，**阻塞渲染** |
| `pagead2.googlesyndication.com` | 6 处 / 3 页 | ❌ 被 GFW 屏蔽 | 同上 + AdSense 容器占位抖动 |
| `hm.baidu.com` | 3 处 | ✅ | 可接受 |

**这是本站最大的性能风险**：脚本加载超时可达 10–30 秒，直接毁掉 LCP。自有资源仅 47 KB，第三方却可能拖几十秒。

**处置**：D-4 拍板（01-PRD §9 Q2）。删除 GA4/AdSense 是收益最大的单项优化。

### 🥈 瓶颈 2：DOM 规模（337 卡片全量渲染）

- 每次筛选/搜索都要遍历 337 个卡片节点；移动端尤其明显。
- 优化方向：分页/虚拟滚动（代价大）、增量筛选（缓存上一次结果集）、或减少首屏卡片数（与 LOCKED 决策"垂类为主通用为辅"需权衡）。

### 🥉 瓶颈 3：源文件未压缩（收益有限）

- CSS/JS 未 minify，但 gzip 后仅 27 KB，收益约 5–8 KB 传输。
- **优先级低**：先解决瓶颈 1 和 2。

## 5. 优化路径（按性价比排序）

| 序 | 动作 | 预期收益 | 成本 | 依赖 |
|---|---|---|---|---|
| 1 | **删除/异步化 GA4 + AdSense** | 消除 10–30 s 超时风险 | 低 | D-4 拍板 |
| 2 | 第三方脚本全部加 `async`/`defer` | 消除阻塞渲染 | 低 | 无 |
| 3 | 百度统计脚本异步化 + preconnect | 减少连接耗时 | 低 | 无 |
| 4 | 筛选算法优化（增量/缓存结果集） | 交互流畅度提升 | 中 | 无 |
| 5 | CSS / JS minify | 传输 -5~8 KB | 低 | 引入构建步骤 |
| 6 | 卡片 HTML 精简（减少冗余属性） | 解析与仓库体积 | 中 | 改 build 模板 |
| 7 | 分页 / 虚拟滚动 | DOM 大幅下降 | 高 | 影响 SEO 静态渲染，**需先验证不破坏生命线** |

> ⚠️ 第 7 项风险：静态全量渲染是 SEO 生命线（13-SEO审计 §4）。任何"按需渲染"方案必须保证**禁用 JS 时内容仍完整可读可点**，否则一律否决。

## 6. 回归与监控

| 时机 | 动作 |
|---|---|
| **每次部署前** | 跑 §7 度量脚本，对比 §2 基线；传输体积增幅 > 20% 需说明原因 |
| **每次部署后** | 浏览器实测 LCP / CLS / TTFB（首屏 + 频道页各一次） |
| **每月** | 记录核心指标趋势；第三方脚本清单核对 |
| **引入第三方脚本** | 过 11-安全审计 §5 + 重测传输预算 |

**回归红线**：

- 首屏第三方域数 > 1 → 不许上线（或经用户显式豁免）。
- 新增阻塞渲染的同步脚本 → 不许上线。
- 首页 HTML 传输 > 30 KB → 不许上线。

## 7. 度量方法（可复现）

### 7.1 体积与 gzip

```python
import gzip
for f in ['index.html', 'assets/css/style.css', 'assets/js/main.js']:
    raw = open(f, 'rb').read()
    gz = gzip.compress(raw, 9)
    print('%-32s raw=%8d gzip=%8d ratio=%.1f%%'
          % (f, len(raw), len(gz), len(gz) / len(raw) * 100))
```

### 7.2 页面清单体积

```bash
find . -name "*.html" -not -path "./.workbuddy/*" -exec ls -l {} \; \
  | awk '{s+=$5; print $5"\t"$9} END {print "TOTAL:"s}'
```

### 7.3 运行时规模

```bash
grep -c "<article" index.html          # 卡片节点数
grep -c "<img"    index.html           # 图片数
```

### 7.4 核心指标

浏览器 DevTools → Lighthouse / Performance 面板，或 Web Vitals。
**注意**：测国内体验要在国内网络下测（境外节点测不出 GFW 超时问题）。
