# 正协导航 · 用例模板（09-用例模板）

> 读者：写验收用例、做发布前检查时直接复制使用。
> 版本：v1.0 ｜ 2026-08-29
> 用法：复制对应模板 → 填「预期」为**可观测**条件 → 逐条执行 → 记录实际结果 → 判定。

---

## 0. 通用用例格式

```markdown
### UC-<类别>-<序号> <用例名>

| 项 | 内容 |
|---|---|
| **前置** | <初始状态 / 数据准备> |
| **步骤** | 1. …<br>2. …<br>3. … |
| **预期** | <可观测、可判定的结果，禁写"正常/可用"> |
| **实际** | <执行后填写> |
| **判定** | ✅ 通过 / ❌ 失败 / ⏭ 跳过（原因） |
| **关联** | PRD § / ADR- / 圆桌 Todo |
```

> ⚠️ **预期写法纪律**：必须能一眼判定。
> ❌ "页面显示正常" ｜ ✅ "结果计数行显示 `当前显示 12 / 337 张卡片`"

## 3. 页面新增用例（UC-P）
