## 2. 实测结果（2026-08-29）

### 2.1 外链安全属性

| 项 | 结果 | 判定 |
|---|---|---|
| `target="_blank"` 总数 | **207** | — |
| 缺 `rel="noopener"` | **0** | ✅ 通过（无 tabnabbing 风险） |
| 含 `nofollow` | 92 | ✅ 符合域名优先级策略（营销/UGC 类） |
| 政务/同域 dofollow | 115 | ✅ 符合 ADR-008 |

### 2.2 代码注入面

| 项 | 结果 | 判定 |
|---|---|---|
| `eval(` | 0 | ✅ |
| `innerHTML =` | 0 | ✅ |
| 内联 `on*` 事件 | 12 处（`index.html` 10、`engine` 1、`gov` 1） | ⚠️ 均为 `onerror="this.remove()"`（图片兜底），存量保留，**新代码禁止新增** |
| 内联 `<script>` | 62 处（4–7 处/页） | ⚠️ 含 FOUC 防护、JSON-LD、统计初始化；为无 CSP 下的必然形态 |

### 2.3 第三方脚本清单

| 域名 | 引用次数 | 用途 | 国内可达性 | 风险 |
|---|---|---|---|---|
| `www.googletagmanager.com` | 11（7 页） | GA4 统计 | ❌ 被 GFW 屏蔽 | 🟠 超时拖慢首屏 + 数据缺失 |
| `pagead2.googlesyndication.com` | 6（3 页） | AdSense 广告 | ❌ 被 GFW 屏蔽 | 🟠 同上 |
| `hm.baidu.com` | 3 | 百度统计 | ✅ | 🟢 |

> **合计 3 个第三方域 / 20 处引用**。首屏请求数超预算（见 14-性能基线）。
> **待拍板**：01-PRD §9 Q2 / CONVENTIONS §5.7 D-4（GA4 + AdSense 去留）。

### 2.4 用户数据与存储

| 项 | 结果 |
|---|---|
| `localStorage` 用途 | 主题偏好（`zx_theme`）+ 本地收藏 |
| 是否含敏感信息 | 否 |
| Cookie | 无第一方 cookie 写入 |
| 表单 | `pages/submit/` 有 4 input + 1 textarea + 1 select，**无 `action`**；`directory/engine/` 有搜索表单 `action="#"` |

> 🔴 **T10 已确认（2026-08-29，与圆桌 #47 增长黑客实站核验结论一致）**：`pages/submit` 表单字段齐全，但提交后**仅保存在浏览器本地、无后端不回流** —— 运营者拿不到 UGC 来源，也拿不到申请人邮箱。用户以为提交成功，实际数据从未离开浏览器。
> 这是**功能 + 合规双重缺陷**：功能上用户诉求丢失；合规上若表单宣称"我们会收到/会处理"则构成不实表述。
> **处置选项**（待用户拍板）：① 改为 `mailto:` 链接提交 ② 接入境内第三方表单服务 ③ 页面明示"暂未开通，请通过联系我们页反馈"。

### 2.5 其他

| 项 | 结果 |
|---|---|
| CSP（Content-Security-Policy） | ❌ **未设置**（无 meta、无响应头） |
| SRI（Subresource Integrity） | ❌ 未使用（第三方脚本无 hash 校验） |
| 裸 IP 外链 | ⚠️ 1 处：`http://202.106.125.196`（同时为 http 明文） |
| HTTPS 外链比例 | 待统计（存在 `http://` 明文外链） |
| `ads.txt` | 存在，含发布商 ID `pub-6434243103158481`（公开信息，非敏感） |

## 3. 已知缺口清单

| # | 缺口 | 级别 | 影响 | 建议处置 |
|---|---|---|---|---|
| **S-1** | 无 CSP | 🟠 P1 | 第三方脚本被篡改时无拦截层 | 引入 CSP 需先消除内联脚本（62 处）或改用 nonce/hash；成本较高，**建议与 D-4（删 GA4/AdSense）联动**：删减第三方后可大幅简化 |
| **S-2** | 第三方脚本无 SRI | 🟡 P2 | 无法校验脚本完整性 | 对自知版本的第三方脚本加 `integrity`；GA4 动态加载不适用 |
| **S-3** | submit 表单无接收端（**已确认**） | 🔴 **P0** | 用户提交静默丢失（功能 + 合规双重） | 明确接收方式（邮箱链接 / 境内第三方表单服务 / 明示"暂未开通"）；**在修复前，须在页面明示"提交不会送达"**，否则构成不实表述 |
| **S-4** | 1 处裸 IP + http 明文外链 | 🟡 P2 | 不可信、可被劫持 | 换 https 域名或移除该条收录 |
| **S-5** | 域名注册锁 / 双因素未确认 | 🟡 P2 | 域名被转移风险 | 在域名商控制台开启注册锁 + 双因素 |
| **S-6** | 无 SRI + 无 CSP 下的 62 处内联脚本 | 🟠 P1 | 与 S-1 同源 | 见 S-1 |

## 5. 引入第三方脚本前检查清单（强制）

新增任何第三方脚本/SDK/字体/统计代码前，逐条勾选，任一项"否"即**不得引入**：

- [ ] **国内可访问性**：目标域名在国内可稳定访问（GA4/AdSense 已因此待复议）
- [ ] **必要性**：现有方案为什么做不到？（说不出 = 不引入）
- [ ] **必要性等级**：是否影响核心功能？非核心一律加 `async`/`defer`
- [ ] **隐私影响**：是否读取/回传用户数据？→ 是则先更新隐私政策（12-合规 §2）
- [ ] **可用性降级**：脚本被墙/超时/被删时，页面是否仍完整可用？
- [ ] **体积与请求数**：是否使首屏超预算（14-性能基线 §3）？
- [ ] **供应链**：是否为官方 CDN？是否有版本锁定或 `integrity`？
- [ ] **登记**：已加入本文 §2.3 第三方清单（域名/用途/引用页数）
- [ ] **测试**：已过 09-用例模板 UC-Sec03 + UC-Perf05

## 6. 治理层暴露面（`.workbuddy/`，T8）

- 仓库为 **public**，治理文档、记忆、备份锚点、圆桌评审内容**对外可见**（ADR-011，用户已明示接受）。
- **红线**：页面层（L1/L2/L3）**严禁暴露 `.workbuddy/` 的存在**（路径/名称/清单/内部工作流）—— CONVENTIONS §1.11。
- **不得入仓**：密钥、口令、真实统计 ID 之外的凭据、`__pycache__/`、`*.pyc`、`.workbuddy/backups/`（`.gitignore` 已涵盖）。
- 当前 `ads.txt` 中的发布商 ID 属 AdSense 规范要求的公开信息，不算泄露。
