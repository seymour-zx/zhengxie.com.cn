# 正协导航（zhengxie.com.cn）百度 SEO 优化策略

> 制定人：百度SEO专家（度优优）　|　日期：2026-08-24
> 范围：地基合规审计 + 站内优化 + 站外生态 + 收量验证
> 适用：Baidu 搜索生态（含移动优先、百度小程序、百度百科/知道/贴吧）

---

## 〇、一句话诊断

本站**内容结构合规、静态可读、Baiduspider 友好**,但被三道硬墙挡在百度首页之外:

1. **境外托管（疑似 GitHub Pages）** —— 百度对境外服务器的站点降权、爬取慢、不稳定,是最致命的基础设施问题。
2. **GA4 + Google AdSense 全站被墙** —— 国内用户/百度统计回传被污染,且 AdSense 在国内填充差、违规风险高。
3. **导航聚合型内容** —— 百度「飓风算法」专门打击低质采集/聚合站,纯链接列表没有原创深度内容会被判低质。

> 这三点不解决,后面所有"关键词布局、外链建设"都是隔靴搔痒。

## 二、优先级行动清单（P0 → P2）

### 🔴 P0 基础设施（不做 = 后续全无效）

**1. 迁移到境内托管 + 完成 ICP 备案**
- 把静态站部署到**国内节点**:阿里云 OSS 静态网站 + CDN / 腾讯云 COS / 华为云 OBS,任选其一,均支持静态托管且国内访问快。
- 备案流程:购买国内云主机/备案服务号 → 在服务商处提交 ICP 备案（非经营性,4–20 个工作日）→ 备案通过后解析域名到国内 IP。
- 百度收益:境外 → 境内,爬取频率、收录速度、排名权重全线提升,这是性价比最高的一步。

**2. 清除 Google 服务,换国内替代**
- 删除全站 GA4 片段（`googletagmanager.com`/`gtag`/`G-B880S4NQVK`）与 AdSense 加载器（`pagead2.googlesyndication.com`/`ca-pub-6434243103158481`）以及 `preconnect`/`dns-prefetch` 到 google 的声明。
- 统计:保留**百度统计（仅本站 ID `2f4df5057c929092e36a0d6357e35261`）**,删掉 info 站冗余 ID。
- 广告:若坚持变现,迁到**百度联盟（百度广告）**;否则先下线广告,等流量起来再接。
- 涉及文件:`index.html`、`directory/*/index.html`、`directory/index.html`、`pages/overview/index.html`、`404.html`、`assets/css/style.css`（广告位样式可保留但注释来源）、`pages/privacy/index.html`（删除 GA4/AdSense 隐私描述）、`ads.txt`（AdSense 专用,可删）。

**3. 验证 ICP + 提交站长平台**
- 在[百度搜索资源平台](https://ziyuan.baidu.com)用**百度统计**或文件验证方式认领站点。
- 提交 `sitemap.xml`（已有 13 条,提交即可）。
- 开启"抓取频次""死链提交""移动适配"监控。

### 🟡 P1 站内内容（抗飓风算法 + 提原创）

**4. 把"聚合"变成"原创价值"**
- 每个 `directory/<name>/` 频道页补充**原创导言 + 选站标准 + 使用场景**,而非只列链接。现有 `build_channel_intro()` 已有雏形,应扩充为 300+ 字原创评述。
- 新增**主题文章页**(如《2026 全国省级政协官网导航与使用指南》《政务工作者必备的 10 类效率工具》),作为频道页的"深度内容"入口,稀释聚合比例。
- 卡片描述(`card__desc`)写入**你自己的筛选点评**(一句话),而非照搬官网 slogan,证明"人工编辑"属性。

**5. 标题 / 描述 百度化（避细雨算法）**
- 百度建议:`<title>` ≤ 30 汉字,`<meta description>` ≤ 78 汉字,避免堆砌。
- 当前根页 title「正协导航 - 让每一次寻找,都不止于找到」合规;但 keywords 列了 12 个词(含"AI工具,效率工具"与政协主题无关),**建议聚焦"政协/政务"垂直词**,避免泛词稀释主题相关性。
- 频道页 title 应含"频道名 + 正协导航 + 价值点",如「政协官网导航 - 正协导航:全国省市级政协入口一站式」。

**6. 内链网状化 + 面包屑**
- 频道页 ↔ 根页 ↔ 文章页互相内链,形成主题集群(thematic cluster),传递权重。
- 加 JSON-LD `BreadcrumbList`,帮助百度理解层级。

**7. 收录加速**
- sitemap 自动维护:在 `build.py` 编排里调用 sitemap 生成,新增频道自动入表(当前手动补,易漏)。
- 主动推送:用百度搜索资源平台"API 推送"(curl 实时推送新 URL),比等爬虫快得多。可写一个小脚本 `push_baidu.py`,在 `build.py` 末尾调用。

### 🟢 P2 站外生态（百度系权重溢出）

**8. 百度百科 / 知道 / 贴吧 / 文库 矩阵**
- **百度百科**:创建/认领「正协导航」词条,引用本站为权威来源之一(百科词条常居品牌词搜索首位)。
- **百度知道**:围绕"政协官网怎么找""民主党派官网有哪些"等问答,自然带出本站。
- **百度贴吧 / 文库**:政务、政协相关贴吧做价值贡献;把导航指南整理成文库文档。

**9. 国内高质量外链**
- 从 `.gov.cn`、政务媒体、行业站点获取友链/引用(你已收录大量政府官网,可争取双向引用)。
- 避免购买外链、点击农场(惊雷算法打击)。

## 三、百度算法风险红绿灯

| 算法 | 对你的风险 | 应对 |
|------|-----------|------|
| 飓风算法（采集/聚合低质） | 🔴 高 | 加原创导言、编辑点评、主题文章,证明人工策展 |
| 细雨算法（B2B/黄页标题堆砌） | 🟡 中 | 标题不堆关键词,聚焦垂直主题 |
| 清风算法（标题党） | 🟢 低 | 当前标题真实,保持 |
| 惊雷算法（刷点击） | 🟢 低 | 不碰点击农场 |
| 蓝天算法（新闻源质量） | ⚪ 不涉及 | 非新闻源 |

## 四、验证指标（上线后 30/90 天对照）

- **收录量**:百度 `site:zhengxie.com.cn` 从当前≈覆盖不全 → 90% 以上已发布页 7 日内收录。
- **排名**:核心词「政协官网导航」「正协导航」「民主党派官网」进前 10。
- **抓取**:搜索资源平台"抓取频次"稳定上升,无大量 5xx/超时。
- **移动**:移动端加载 < 2s(境内 CDN 后可达)。
- **合规**:搜索资源平台零严重错误,ICP 备案号展示于 footer。

## 五、给技术同学的落地备注

- 删除 Google 片段时,`build_homeplus.py` 模板里的统计/广告注入块要同步改,否则下次 `build.py` 又生成回去。
- `pages/overview/index.html` 是手写页(不在 build 流程内),需单独改统计片段。
- `ads.txt` 为 AdSense 专用授权文件,迁联盟或下线广告后应删除,避免误导。
- 迁移境内托管后,Cloudflare 可保留做 DNS/SSL,但**回源/CDN 节点必须国内**,否则仍是境外。
