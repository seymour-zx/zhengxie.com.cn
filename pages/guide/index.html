使用指南

正协导航把复杂的功能做简单。下面是一分钟上手的核心操作。

一、本地收藏

每张卡片上的收藏按钮（☆）可将站点加入你的常用清单。收藏数据仅保存在你当前浏览器的本地存储，不上传服务器、不跨设备同步。

  • 点击卡片收藏按钮即可加入 / 取消收藏；
  • 在筛选区选择「我的收藏」可只看收藏站点；
  • 清除浏览器站点数据或更换设备后，收藏会重置。

二、三维度筛选

通过分类 + 关键词 + 本地收藏三个维度叠加，精准定位目标站点：

  • 分类：按导航大类快速收窄范围；
  • 关键词：在搜索框输入名称或描述实时过滤；
  • 本地收藏：仅显示你收藏过的站点。

三、集合搜索

选中卡片后，可在集合搜索区一键切换百度、Google、必应及多个垂直引擎进行检索，结果在新窗口打开，不打断你的浏览。

四、URL 分享与随机漫步

  • URL 分享：当前筛选状态会写入地址栏（如 #cat=AI智能），复制链接即可分享同一视图；
  • 随机漫步：点击随机按钮，随机推荐一张卡片，发现未知的好去处。

五、暗色模式与快捷键

  • 暗色模式：点击页脚或右下角切换按钮，偏好记于本机，仅本设备生效；
  • 快捷键：按 / 快速聚焦搜索框。
