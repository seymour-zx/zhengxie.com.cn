关于本站

正协导航是一个全量收录的精选站点导航站。我们的目标是让每一次寻找，都不止于找到——不仅帮你快速抵达目的地，更帮你发现那些值得驻足的好站点。

站点覆盖常用入口、AI智能、资讯媒体、设计创意、开发技术、学习教育、效率工具、影音娱乐等分类。每一类都经过精选，确保收录的站点质量过硬、内容可靠。

设计理念

采用奢华尊贵风设计：主色红色系，搭配金色系与白色系，大面积白色背景，大气简洁不压抑。卡片采用黄金比例布局，细节之处见匠心。

功能特色

  • 三维度筛选：分类 + 关键词 + 本地收藏，AND 叠加精准定位
  • 集合搜索引擎：百度、Google、必应 + 16 个垂直引擎一键切换
  • 本地收藏：一键收藏常去站点，浏览器本地持久化
  • 暗色模式：护眼夜间浏览，自动跟随系统偏好
  • 键盘快捷键：按 / 快速聚焦搜索
  • URL 分享：筛选状态可通过链接分享（如 #cat=AI智能）
  • 随机漫步：随机推荐一张卡片，发现未知的好去处
  • SEO 友好：全静态渲染，搜索引擎可直接抓取

技术栈

纯静态站点，无后端框架。数据源为 Excel 表格，由 Python 脚本生成静态 HTML。前端使用原生 CSS + JavaScript，不依赖任何框架库。通过 GitHub Pages 部署，自有域名 + 自动 HTTPS。
