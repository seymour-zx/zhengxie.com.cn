# site_data.xlsx 字段清单（单一真值源 · 扁平行模型）

> 来源：`directory/_master/site_data.xlsx`｜工作表：`全量数据`｜当前 **36 列 / 414 行**
> 模型规则（来自 build_site.py）：
> - 每一行 = 一个站点（`url` 非空）= 一条可点链接
> - 同 `page_id` 的行自动归一个页面（页面级字段取该 `page_id` 首行非空值）
> - 同 `card_id` 的行自动归一张卡片（卡片级字段取该 `card_id` 首行非空值）
> - `url` 为空 且 `slot_key` 非空 = 该页"同位置文本"槽位（如 hero_title / footer_note）
> - `attest_card_id` 非空 = 挂在某张卡片下的「认证/凭证徽章」行（非主链接）
>
> **你只要在这张表上填两列即可：**
> - 「保留?」填 留 / 删 / 改（改=名字或含义要变）
> - 「你的作用说明」填这个字段你想拿来做什么、给谁看、要不要进页面/JSON-LD
>
> 填完发我，我据此定稿 `site_data.xlsx` 的列结构与 `build_site.py` 的渲染/校验。
